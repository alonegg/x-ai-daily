  • #DeepSeek V4.1-Flash-1017：输出更短、开源 MIT，搜索引擎开放为 API长推
    宝玉 · meng shao · DeepSeek · 歸藏 等 7 位

    DeepSeek 发布 V4.1-Flash 的增量更新版 V4.1-Flash-1017（日期后缀命名，不是架构换代），官方称基准分数更高、完成任务更快、输出更短，是性能与成本的「帕累托改进」；官网、App 已切到新版，API 模型名仍是 deepseek-flash，代码不用改。

    宝玉梳理：这一版主攻从零完成整个项目（演示从头做小游戏和 3D 模型），进步最大的是命令行 agent 测试 Terminal-Bench，从 31.2 分升到 42.3 分；和 Opus 5 相比，几项自动办事测试分数更高，高难度问答和写完整程序仍然落后，这些都是 DeepSeek 自测。

    模型以 MIT 协议开源、允许商用，可在 Hugging Face 和魔搭下载，共 7630 亿参数，主要面向企业和云厂商自部署。meng shao

    补充训练用了「带自我反馈的强化学习」，目标是完整长任务的最终结果，DeepSWE v1.1 得 77.0；模型卡主要对比 K3、GLM-5.3、GPT-5.6；已适配 DeepSeek Harness（需 v0.2.1-rc.1 及以上）、腾讯 CodeBuddy、WorkBuddy，API 也直接兼容 Claude Code 和 Codex 的服务端工具调用。

    商业上，DeepSeek 把内部搜索引擎开放成两个 API：Search（/v1/tools/search，返回结构化网页结果，支持 site:、lang:、after: 等算子）和 Fetch（/v1/tools/fetch，把网页抓成 Markdown）。

    每个接口每 1000 次成功请求收 5 元（英文版标 0.75 美元），失败、没结果、超时不收费；在 Claude Code、Codex、DeepSeek Harness 里由 AI 自动发起的搜索和抓取目前免费，北京时间 11 月 1 日 0 点起按次收费。

    社区反应：歸藏觉得 DeepSeek 在自家 DeepSeek SWE v1.1 基准上的图「有点离谱，完爆所有模型」，用他给 Opus 5.5 写的游戏特效提示词实测，细节和创意差 Opus 5.5 不少，但「能用」，并认为它的中文搜索结果很准，适合接进 harness；Gorden Sun 认为它能力和速度都超过 GPT 5.6 Sol，「跑分超过 Kimi K3 和 GLM 5.3」；

    向阳乔木已把自己 RSS 网站的翻译模型换成新版（思考强度 High）；yetone 的 Magpie 从 v0.1.1281 起可选 DeepSeek Search API 作为网页搜索提供方。

  • #开源模型速递：MOSS Image、NVIDIA Dory1.0-4B、阿里 MAI-Gym、微软 AesCode、MJev-Spatial
    Gorden Sun · HF Papers

    OpenMOSS 开源 5.6B 参数的生图模型 MOSS Image，Gorden Sun 实测中文字写得不错，但推理能力很弱，图里要写中文时得在提示词里写明具体文字。NVIDIA 在 Hugging Face 发布 Dory1.0-4B：循环式潜在递归 LLM，推理时可选 1、2 或 4 次循环，用算力换准确率，不用重新训练，256K 上下文，另有 MXFP8、NVFP4、GGUF 版本。

    阿里通义 Tongyi-MAI 开源 MAI-Gym：覆盖手机、电脑、网页的 GUI agent 一体化评测与在线 RL 平台，其 9B 模型在 MobileWorld 上 78.4%、OSWorld-Verified 上 76.2%。微软 AesCode（8B / 32B）用解耦的跨模态奖励做「审美代码生成」，以图像生成模型作视觉引导，把提示词变成可编辑、可验证的 HTML/CSS 信息图。

    MJev-Spatial-4B 是基于 Qwen3.5-4B 的多模态「决策模型」，空间问题用直接分类回答、不生成自回归答案 token，在 12 个基准中的 7 个上总分最好，比基座快 5.6 倍。

  • #Claude Code 代码评审文章发酵：宝玉「瑞士奶酪」讲解视频，meng shao 补出收敛数据后续长推
    宝玉 · meng shao · Gorden Sun · Daniel San
    前情Anthropic《How the Claude Code team does code review》的主要内容昨天已收录。 接 10-17 ↩

    宝玉发布中英双语讲解视频和完整文稿，用「一摞带洞的奶酪片 + 底下一张网」来讲：每道检查都会漏，叠起来就很难漏；人的时间花在审代码和救火两头，只省前一头没有意义。他按一次修改的流程讲了一遍（自验→CI 自动检查→多 AI 并行找问题再投票→安全审查→按风险定人工审批→合并队列→功能开关与分批发布→快速撤回），并回答五个问题：哪些修改还要人看，AI 审 AI 会不会没完（三轮封顶后，一轮通过率 65%→78%，要五轮以上的从 8.9% 降到 1.5%），审查 AI 漏了怎么办（拿历史事故做「错题本」每日评测），人不读代码怎么懂代码（让 Claude 为要动的那块代码现写讲解），出了事算谁的（「你合并的你负责」，复盘不追究个人，只问「本该由哪一片奶酪拦住」）。

    meng shao 的长文拆解

    补充团队不追踪「评审覆盖率」，而是追踪每个 PR 平均几个人审批和等待时长，以回滚率和事故率作护栏；Boris Cherny 认为给 Claude 一个验证方法是「最重要的事」，效果能提升 2–3 倍；发现分 Important / Nit / Pre-existing 三类；PR 模板强制写「如何测试」和「如何回滚」；批准只对单个 commit 有效，有新提交就要重审；平均评审轮次从 2.08 降到 1.32。

    Gorden Sun 总结人类剩下的五件事：该不该做、高危代码、架构、审「证据」、为结果兜底。Daniel San 最感兴趣的是如何防止 agent 互审死循环，并预告要写一篇按预算和需求比较各种 agent 代码评审方案的文章。

  • #poteto 的「倒金字塔」：要信任 agent，先改代码库长推
    meng shao · Lauren

    meng shao 解读 Grok Bot 团队 Lauren（@poteto）提出的四层框架，精力投入从上到下递减：①代码库改进（投入最多）——更好的架构、更强的类型与不变量、清晰的模块边界；agent 天生爱复制现有代码、走最短路径，那就让最短路径本身是对的；②静态分析——lint、测试、CI、形式化验证（如 TLA+），token 成本极低，反馈是确定性的；③文字性指导（尽量少用）——注释、AGENTS.md、Skill 描述，弱点是无法强制执行；

    ④人工审查（最难规模化）——人的精力应该投向「设计让 agent 默认就做对的环境」。之所以是「倒置」的，是因为越往上手段越确定、越省 token，越往下越依赖不可靠的理解和不可扩展的人力。meng shao 认为这比「从 prompt 工程转向上下文工程」更进一步：连提示词也只是第三等手段，真正的杠杆在代码库里。

  • #Anthropic 官方插件 project-artifact：把仓库变成可刷新的项目状态页长推
    Daniel San

    Daniel San 介绍 Anthropic 的 project-artifact 插件：读取仓库、PR、任务跟踪器或设计文档，发布为可分享给团队的私有 Claude artifact，包含概览、成功标准、工作流和下一步，只有确实有内容时才加风险、计划、FAQ 标签页。

    它把 PR 编号成 1.0、1.1、2.0 来体现依赖关系，用 gh CLI 拉取 PR、CI 和评审状态。每个项目存一份配置，任何会话里说一句「refresh the artifact」都会更新同一个 URL，并标出变化。抓取失败时把数据标成过期而不是猜测，PR 文本只当数据、不当指令。

    安装用 /plugin install project-artifact@claude-plugins-official，运行 /project-artifact。

  • #Buehler：从静态论文到「活的科学记录」，去中心化多 agent 做材料发现长推
    Markus J. Buehler

    MIT 的 Markus Buehler 团队在 MRS Bulletin 发表观点文章《Toward living scientific records through decentralized multi-agent systems for materials discovery》（Wang、Berkovich、Marom 等，2026）。

    核心主张：科学发现正从人工编排工具和中央规划的 AI 工作流，转向通过一份共享的「活的科学记录」自主协调的去中心化系统。这份记录是一张带溯源链接的图，持续记录证据、假设、失败、批评和悬而未决的问题；论文、方法、数据集和批评都成为它的「视图」，人和 AI agent 都能检查、复现、质疑和扩展。

    他们的实现是 ScienceClaw × Infinite：数百个 AI 可调用的科学技能注册表，加一个共享的「工件与需求公共池」——agent 广播未满足的需求，按「压力」排序，自行认领关键空缺，没有中央规划者分派任务（类似白蚁无建筑师筑巢的 stigmergy）。

    案例：把蛛丝、鸟类鸣管膜、蟋蟀翅膀、声子晶体、乐器结构等 15 种共振体放进同一个六维特征空间，群体找到工程设计稀疏的区域；第一个候选偏离目标 2.12 个单位，系统根据候选自身几何算出的坐标发现了偏差，重新设计出预张紧柔性膜板，误差降到 0.007，再做有限元模态筛选（最低 10 阶弹性模态在 74.8–411.6 Hz）。

    要点：知识的持久单位决定科学方法，活的记录把它从「整理过的产出」推向「整理过的过程」；出版变成接口，评审可以细到单个节点；失败结果会保留，假设可复用、可组合；但持久不等于可信，还需要质量分、不确定性字段、对抗式评审和人的问责。他认为这扩展了开放科学的定义——开放的不只是最终结果，还有它如何得出的可执行、可检查、可持续扩展的完整记录。论文提供免费访问链接。
