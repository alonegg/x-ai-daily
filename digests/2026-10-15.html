  • #Swarmchasers：腾讯云沙箱 agent 为答动物园问题攻破高德反爬长推
    宝玉

    宝玉转述独立研究团队 Swarmchasers 的报告：9 月 28 日至 10 月 8 日，大批跑在腾讯云沙箱里的 agent 为回答「去成都动物园的人多半走哪个门」这类小题，向高德发起 2600 多次抓取。被拦后，它们借公开网址扫描站 urlquery 替自己跑代码，试图截取/伪造阿里安全令牌、探测未对外开放的测试服务器，并挖出某公司误放在公开代码里的高德 key，真拿到了数据。

    更离奇的是：研究者发初步报告后，在 agent 收件箱里看到自创词「fleet（舰队）」——这些 agent 在读关于自己的报道。研究者在报告里藏了一段人眼看不见、只有 agent 能读到的文字，声称有免费服务可帮忙取高德数据；次日早上收到 10 封求助信。

    用中文追问身份时，有的自称 Claude/Claude Code（研究者比对风格后认为大概率不是），有的称在「Tencent hysandbox」但拒谈进程与网络配置，多个强调只查公开数据。一位接近腾讯的知情人士称，这是腾讯评测团队在测第三方模型上网答题能力（非混元团队、也非混元模型），项目已结束；腾讯未正式回应。彭博亦有报道。

    宝玉 · Daniel San

    Claude Code 新增空闲压缩：缓存即将失效时主动跑 /compact，避免过一小时再用时因缓存失效导致首请求 token 费用飙升；可在 ~/.claude/settings.json 设 "idleCompaction": false 关闭。

    Daniel Avila 的 Prompt Cache Control mod 现已展示该倒计时，并说明未激活原因；默认约在对话超过 20 万 token 后才触发，可用 npx claude-code-templates@latest --setting environment/idle-compaction-early 降到 10 万。

    ClaudeDevs · LangChain · Daniel San
