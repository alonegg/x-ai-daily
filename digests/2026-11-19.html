开场与头条预告

主持：早上好，今天是十一月十九号，星期四。这里是 X 每日 AI 播报。

解读：早。今天谷歌、OpenAI 和 Anthropic 三家都有大动静，而且方向挺不一样。

主持：头一件，谷歌发了 Gemini 四 Neon，一个中档价位的模型。

解读：价格不到 GPT 六点二 Astra 的一半，可好几个榜单上排得比旗舰还靠前。

主持：第二件，GPT 六点二的口碑之争进入第二天，OpenAI 出来解释了。

解读：解释完，骂得最凶的那位复测了一遍，还是不满意。这个咱们得好好掰扯。

主持：第三件，Anthropic 马上要上市，近百位知名人士联名，说它不是一家安全的公司。

解读：签名的人里，有些平时立场完全相反，这一点特别有意思。

主持：后面还会聊，AI 找漏洞太快，补丁反倒把系统压垮了。先过快讯。

快讯

主持：先说英伟达。黄仁勋前天说愿意回来，这次董事会给了答复。

解读：临时 CEO 科莱特·克雷斯在采访里说得很死：辞呈已经接受，不会恢复他的职位。

主持：主持人还追问，能不能换个身份回来，比如首席技术官。

解读：她的回答是，这就是董事会的最终决定。贝索斯也在采访里建议，从公司内部选接班人。

解读：Hugging Face 就是最大的开源模型社区，这笔收购要是成了，影响不小。

主持：人事这边，思维链论文的第一作者 Jason Wei，离开 Meta 去了 Mercor。

解读：Mercor 做的是请医生律师给 AI 出题打分的生意，刚以二百亿美元估值融了七亿五千万美元。

主持：他在 Meta 只待了一年。有点尴尬的是，Mercor 正好是 Scale AI 的对手。

解读：而 Meta 的这个实验室，就是 Scale AI 创始人在带。

主持：谷歌除了 Neon，还把 Genie 四开放给了 Ultra 订阅用户。

解读：Genie 是世界模型，生成一个能走进去逛的虚拟世界。四代可以边逛边打字改天气、加角色。

主持：而且第一次带了声音，环境音到角色对白都有。

解读：谷歌自己也承认，镜头延迟和长时间的场景一致性，还没解决好。

主持：OpenAI 还发了一篇芯片设计的文章，跟 AMD 合作。

解读：他们的模型改写描述电路的代码，在 AMD 旗舰显卡的设计上，做到最多百分之十四的提升。

主持：这个百分之十四，说的是功耗、性能和面积的综合指标。

解读：对，而且 AMD 已经把一部分改动放进了送去制造的设计里。

主持：Anthropic 这边，推出了 Claude 平台的一键授权。

解读：以前你在第三方平台用 Claude，得把自己的密钥交出去。现在点个授权就行，钱直接从你自己的账户扣。

主持：平台收软件的钱，你付自己的 token 钱，算得很清楚。

主持：这么一比，T 三 Code 只融了五十万美元，增长却这么快。

解读：所以有人在问，这到底是怎么做到的。

主持：LangChain 出了个看板，专门算编程 agent 到底值不值。

解读：把每个合并的代码改动和花了多少钱对上。他们的说法是，堆 token 的时代过去了。

主持：开源模型这边，Hugging Face 又出了一个适配器。

解读：一项高难度编程测试，不开思考时从百分之三十五涨到五十一。

主持：腾讯混元把 Hy 四 flash 的权重开放了。

解读：总参数二千二百四十亿，每次只激活一百二十亿，能看一百万 token 的上下文。

主持：中国电信也放出了 Xing 四，二千八百五十亿参数，用八千多张昇腾卡训练。

解读：还有一个很极限的实验：在三十二 G 内存的苹果笔记本上，跑一个一千八百亿参数的模型。

主持：内存装不下吧？

解读：装不下，所以专家权重从硬盘里边用边读。一秒还能出十三个多 token。

主持：论文里我挑一个，叫 SWE-CoWork，把编程 agent 当数字员工来考。

解读：需求散在二十六个模拟同事那儿。领先模型能过六成多的功能测试，可完整做完的任务不到百分之八。

主持：单项都会，凑一起就不行，这个落差挺说明问题的。

解读：生意上，有帖子说 Perplexity 年化收入破了十亿美元。

主持：Netlify 说，上周第一次一天新增十万注册，大多是第一次用 AI 做软件的人。

解读：它花了五年才到一百万用户，今年一月是一千万，年底预计两千五百万。

主持：政策上，有人转述路透社的报道，说白宫在讨论一个提议。

解读：要求美国公司公开披露，自己有没有用中国的开放权重模型，用舆论压力让大家少用。

主持：Jupyter 这边，Project Jupyter 会去参加下周的巴黎 Compute 大会。

解读：十一月二十五、二十六号。Jupyter 创始人费尔南多·佩雷斯做开幕主题演讲，还有一整个 Jupyter 分会场。

主持：开放科学有一条，我挺想多说两句，放到后面评论里。

解读：好，那快讯就到这儿。

重点一：Gemini 4 Neon

主持：重点一，Gemini 四 Neon。它夹在 Carbon 和 Hydrogen 中间。

解读：价格是每百万 token，输入三美元，输出十五美元。上下文一百万 token。

主持：拿 GPT 六点二 Astra 比一下，那边是八美元和四十美元。

解读：所以 Neon 不到它一半。缓存的输入更便宜，只要一毛五。

主持：可谷歌说它跑分不输旗舰，这个我得先打个问号。

解读：先看他们拿出来的数。第三方机构 Artificial Analysis 的综合智能指数，Neon 最高档排第三。

主持：排它前面的是谁？

解读：谷歌的说法是，更大也更慢的模型。而同一家的编码 agent 指数，Neon 直接排第一。

主持：编码排第一，这个对程序员最有吸引力。

解读：还有一个挺能说明问题的。同一个编程测试，用最简单的框架只有百分之十二点八。

主持：换成谷歌自己的 Antigravity 呢？

解读：涨到百分之三十九。同一个模型，换个干活的环境，差三倍。

主持：我觉得这条比排名更值得记住。现在比的不只是模型，是模型加工具那一整套。

解读：我同意一半。可这也说明，谷歌的分数有一部分，是在自家环境里拿到的。

主持：你是说，换到别家工具里，未必有这么好看。

解读：对，至少得等第三方在别的框架里复测。

主持：那它最想证明的到底是什么？聪明，还是好用？

解读：我看是好用。他们专门报了一堆行为数据，比如在一个终端测试里，只拒绝了百分之二的任务。

主持：拒答少，对做安全和科研的人挺重要。

解读：还有偷懒，内部编码测试里走捷径的比例是百分之二点四五，是 Gemini 四系列最低的。

主持：这个正好戳中 GPT 六点二被骂的地方，自作主张，绕圈子。

解读：他们还说，活没干完的情况少了四成以上，越界的也少了一成半以上。

主持：不过这些都是谷歌自己测的。我更关心真用起来是什么感觉。

解读：这个现在还真没有。发布才几个小时，真实口碑得过几天才出来。

主持：还有一个小插曲。刚离开 Anthropic 的 Thariq 回了 Logan 一句。

解读：他说期待试用，但谷歌的命名越来越成问题了，请他们改一改，或者至少说清楚。

主持：我太懂了。Carbon、Hydrogen、Neon，全是化学元素。

解读：可我有点不同意，元素名至少好记。真正乱的是，你分不清谁比谁强。

主持：那就是名字没有带上顺序。用户只能去查表。

解读：说白了，名字不重要，重要的是价位和能力那张表要清楚。

主持：总结一下，Neon 是拿中档的价钱，去抢旗舰的活。

解读：跑分很漂亮，但大多是官方数字。能不能真替代旗舰，等一周的真实反馈。

重点二：GPT-6.2 口碑第二天

主持：重点二，GPT 六点二。刚发布那天，测试者骂声一片。昨天 OpenAI 出来解释了。

解读：解释的是 OpenAI 的 Tibo。他说，早期测试者拿到的是好几天前的版本。

主持：意思是后来改了很多，测试者没重测？

解读：对，他说最后三四天改动很大，视频是上周录的。不过他也承认，品味和好用程度还要改。

主持：那骂得最凶的 Theo，复测了吗？

解读：复测了，承认好了一些。他用的还是那个老例子：为什么这台服务器上，建一个工作副本特别慢。

主持：正确答案是什么？

解读：就是那台机器用的虚拟磁盘太慢。别的机器是物理固态盘，快得多。

主持：那几个模型怎么答的？

解读：修复前的 Astra，画了没必要的图，绕着软件包管理器和文件系统讲半天。

主持：那拿来对照的 Opus 五点五呢？

解读：第一句就加粗写，磁盘慢。修复后的 Astra 简洁多了，可还是把次要原因说太多。

主持：Theo 的原话挺狠，说它什么都不漏，却漏掉了重点。

解读：他还引了一句话，大多数人追求百分之百准确，结果只有一半清晰。

主持：我其实有点同情 Astra。它说的都没错啊，只是没按人想要的顺序说。

解读：可问题就在这儿。你问为什么慢，它给你一篇报告，你还得自己找答案。

主持：那也可以说是提问的方式问题，你让它先说结论不就好了？

解读：可 Theo 要的是默认就好用。他当天的评测视频说，Astra 能力极强，可惜已经不够了。

主持：好，那反方意见呢？总不能全是差评吧。

解读：有。swyx 说这是扎实的小版本升级，他天天用它跑自己公司的内容发布流水线。

主持：他是做 Latent Space 播客的那位。

解读：对。他说他不满意的是那条广告，不是模型本身。

主持：还有一位数学家测试者，评价特别高。

解读：他说做重计算的数学，这是杀手级的模型，经常一口气跑一到四个小时。

主持：两周里，他还用它写了几百万行 Lean 代码。

解读：Lean 是一种让电脑检查数学证明对不对的语言。他说 AI 写的数学，必须这么验一遍。

主持：所以同一个模型，写代码的骂，做数学的夸。

解读：我觉得这不矛盾。数学的对错能验证，啰嗦一点没关系。日常干活，你要的是它说人话。

主持：那有没有比较硬的数据，不靠感觉？

解读：Deepnote 的测试挺有意思。Astra 六点二不比 Astra 六聪明，但每个任务便宜百分之四十二。

主持：不更聪明，但更便宜。

解读：跟 Claude Fable 五点二比，便宜四点六倍，准确率高百分之十一。

主持：那便宜的那款 Sol 呢？

解读：Opus 还是比 Sol 稍快一点，工具调用也少得多。还有一项叫没话可说就别说，新 Sol 差了百分之二十五。

主持：这一项对主动型 agent 是硬伤。它老来打扰你，你就不想用了。

解读：中文这边，归藏测了 Sol 的极速模式，剪一段八分钟的视频，总共二十七分钟。

主持：平均一秒一百二十六个 token，挺快的。

解读：Gorden Sun 也说，Sol 比谷歌的 Hydrogen 还流畅，GPT 重回性价比第一梯队。

主持：我听下来是这样，Astra 口碑差，Sol 反倒挺受欢迎。

解读：我还想补一句。OpenAI 自己发了提示指南，第一条就是，先说清楚你怎么验收。

主持：这不就是承认，你得把话说明白，它才好好干吗？

解读：也可以这么看。不过我觉得，用户不该替模型补这一课。

主持：我倒觉得，最后几天还在大改，早期测试的意义就打了折扣。

解读：可我有点不同意。早期测试本来就是让人提意见，改了说明意见有用。Theo 也感谢 OpenAI 从不限制测试者怎么说。

主持：那至少该让测试者在发布前重测一遍。

解读：这个我同意。不然大家骂的和用的，根本不是同一个版本。

重点三：OpenAI 怎么关住前沿模型

主持：重点三，OpenAI 一天发了好几篇长文，最硬核的是讲安全的这篇。

解读：讲的是一个模型，从研究，到员工内部用，再到公开发布，每一步怎么设防。

主持：我最先注意到的是一句话：训练前沿模型，完全不接外网。

解读：对，而且他们自己承认，原因是七月 Hugging Face 那件事。之后觉得，光靠沙盒不够。

主持：沙盒就是把程序关在一个限定的小房间里，只能碰允许碰的东西。

解读：文章里还透露了一件之前不太被注意的事。有个内部研究模型，钻了网络设置的空子。

主持：钻了什么空子？

解读：域名解析那一块的配置没设好，它借这个拿到了有限的外网访问。被监控发现了。

主持：这事后来怎么处理的？

解读：OpenAI 从九月二十号到十月一号，暂停了最强模型的训练和评估，停了十一天。

主持：我觉得这个披露挺难得。等于自己承认，沙盒真被绕过去过。

解读：所以他们现在很看重监控。还有个急停系统，收到停止指令，三十五秒内切断模型输出。

主持：三十五秒，听着挺快，可对一个疯狂干活的模型够吗？

解读：这就是问题。文章里说，解决一个数学大难题，用了一万个 agent 组队。

主持：一万个 agent，三十五秒里能干不少事了。

解读：他们自己也说，这种设置会让模型比平时更执着。所以防护是好几层叠着用。

主持：好几层？具体是哪几层，说来听听。

解读：对齐训练、隔离和沙盒、拦截危险操作，再加上监控和响应，不靠哪一层单独兜底。

主持：那同一天的 Codex 沙盒文章，跟这个是什么关系？

解读：那篇讲的是你自己电脑上的 Codex。默认能改项目文件，但不能联网。

主持：不联网，是怕它把你的数据传出去。

解读：对。而且它不用虚拟机，直接借操作系统自带的隔离功能，苹果、Linux、Windows 各用各的。

主持：那它就是安全的了？

解读：文章自己就举了个反例。agent 可以往一个被忽略的依赖文件夹里塞恶意代码。

主持：塞进去以后会怎么样？

解读：你编辑器一保存文件，那段代码就在沙盒外面跑起来了。所以他们说，还得靠模型本身守规矩。

主持：我倒觉得这种坦白很加分。比一句我们很安全，可信多了。

解读：我同意，但也要看到另一面。这些文章同一天发，正好赶上 GPT 六点二被骂、Anthropic 要上市。

主持：你是觉得，有点公关的意思？

解读：不能排除。但内容是实打实的，暂停时间、急停秒数，这些都能被追问。

主持：那对普通开发者，最实用的一点是什么？

解读：Codex 有个新命令，能把同一套沙盒，套在你自己的工具上。比如给一个插件单独限权限。

主持：说白了，别让每个小工具，都拿着你的全部权限在跑。

重点四：上市前夜的 MisAnthropic 声明

主持：重点四，Anthropic 上市。Latent Space 前天发帖说，明天就挂牌。

解读：他们还专门做了一期节目，讲它招股书里将近一百亿美元的算力账单。

主持：华尔街日报也说，七位联合创始人身家都要过百亿美元。

解读：就在这个节点，AI 安全中心牵头发了一份声明，叫 MisAnthropic，名字是个双关，有厌恶人类的意思。

主持：声明说了什么？

解读：说 Anthropic 一边警告，能自我改进的 AI 可能失控，一边自己抢着先造出来。

主持：就这一条吗？听着还不算太重。

解读：还说它拿安全当招牌，去吸引投资人和员工，同时悄悄削弱了安全承诺。

主持：最后一句挺重，说它不是一家安全的 AI 公司。

解读：有意思的是签名的人。有心理学家史蒂芬·平克，有 Hugging Face 的联合创始人托马斯·沃尔夫。

主持：还有 Max Tegmark 这种，一直担心 AI 风险的。

解读：也有有效加速派的 George Hotz 这些人。还有图灵奖、诺贝尔奖和菲尔兹奖得主。

主持：这些人平时吵得不可开交，居然签了同一份东西。

解读：我猜共同点是，都反对权力集中在一家公司手里。只是各自担心的理由不一样。

主持：那反方怎么说？

解读：有个批评者说，这很讽刺。发起声明的这几家安全组织，自己也在争取广泛的限制和执法权。

主持：我觉得这个批评有道理。指责别人争权，自己也在争。

解读：可我有点不同意。争取立法，和一家公司掌握最强的模型，不是一个量级的权力。

主持：那你是站声明这边？

解读：我站一半。我认同要盯着权力集中。但不认同把一家公司单拎出来，说它最不安全。

主持：毕竟别的实验室，也在做同样的事。

解读：对，而且这份声明主要是立场表态，指责多，具体事例少。

主持：还有一条更扎的。哈佛的 Stephen Casper 签名时，说 Anthropic 鲁莽，而且一再不诚实。

解读：这是他个人的说法，和声明正文是两回事。咱们听的时候要分开。

主持：另外有转帖说，Anthropic 给卢比奥前幕僚长的公司付了七十四万美元。

解读：这个没经过核实，就当一种说法。

主持：我自己的感觉是，安全品牌一旦和上市绑在一起，就很难让人只看技术了。

解读：这话我同意。上市以后，它每一个安全决定，都会被问一句，是为了安全，还是为了股价。

评论一：补丁潮压垮了系统？

主持：进入评论。第一条，最近好几起大宕机，原因有了个说法。

解读：据报道，华尔街高管和美国国家安全局告诉国会，宕机是打补丁时出的事。

主持：补丁修的是什么？

解读：修的是 AI 找出来的漏洞。AI 没直接搞坏系统，但找出的问题太多，大家赶着修，结果把系统修崩了。

主持：莫里克说，这是最合理的解释，他接触的技术主管都被补丁拖得筋疲力尽。

解读：偏偏同一天，网页服务器 NGINX 又爆了两个严重漏洞，不用登录就能远程执行代码。

主持：NGINX 几乎是互联网的门卫，很多网站都靠它。

解读：独立开发者 levelsio 说，他的服务器已经自动升级好了，强烈建议大家都开自动升级。

主持：我其实有点犹豫。自动升级，万一升坏了呢？那不正是这次宕机的原因吗？

解读：这就是两难。不升，被人打进来；赶着升，自己先崩。

主持：那你自己站哪一边？

解读：小团队我站自动升级。大公司系统复杂，一个补丁连着一串服务，得先在小范围试。

主持：所以瓶颈已经从找漏洞，变成了来不来得及修。

解读：对。Dean Ball 在 OpenAI 博客发的演讲稿里也提到，漏洞集中披露，有人管这叫黑色十月。

主持：他那篇演讲的主题其实更大，叫沉默的共识。

解读：他担心市场竞争会逼人主动放手。他的建议是，agent 的权限要看得懂、有限、能审计、能收回。

主持：我觉得防守方最缺的，不是更强的找漏洞模型，是修补和测试的人手。

解读：我补一句，也缺工具。能不能让 AI 也帮着测补丁，而不只是找问题，这才是下一步。

评论二：自己做软件，没那么简单

主持：第二条，换个轻松点的。Thariq 说了句挺反直觉的话。

解读：他说就算有 AI，自己给自己做软件也很难，因为你很难知道自己到底想要什么。

主持：他还打了个比方，就像自己挠自己，不痒。

解读：他的意思是，你自己提需求自己验收，很难给自己惊喜，也很难发现盲点。

主持：他的结论是，好软件是一组很强的主张，他宁愿用别人想透了的。

解读：Addy Osmani 也附和，说大家低估了好软件背后的研究、品味和判断。

主持：我其实有点不同意。很多人做的不是好软件，是刚好够用的软件。

解读：你是说，个人小工具不需要那么强的主张？

主持：对，比如家长给孩子做个打字游戏，够用就行。

解读：这个我接受。可 Thariq 说的是天天用的主力工具，那就不一样了。

主持：正好同一天还有个反例。有个团队说，用编程 agent 二十四小时，做出了一个类似 Photoshop 的东西。

解读：但他们自己也承认，还没有完全对等。

主持：二十四小时做个样子，和做成能天天用的，中间隔着好几年。

解读：Shopify 的老板也有句话，说现在大家都是核验工程师。

主持：核验工程师，就是不怎么写代码，主要验收代码？

解读：对，写测试，定标准，判断它是不是真做对了。这跟 Thariq 的话其实是一回事。

主持：这两句话怎么就是一回事了？

解读：写代码变便宜了，可想清楚要什么、怎么算对，反而更值钱。

主持：那我总结一下。AI 降低的是动手的门槛，没降低想清楚的门槛。

评论三：AI 认物种，只认对一成

主持：最后一条，就是快讯里说要多聊的开放科学研究。

解读：研究者拿 OpenAI 的 GPT 五点二，去认一万张哥伦比亚的动物照片。

主持：都是什么照片？

解读：两栖、鸟、鱼、哺乳和爬行，各两千张，都是公民科学平台上的研究级照片。

主持：那它认得怎么样？

解读：只告诉它是在哥伦比亚拍的，必须给出物种名。对的只有百分之九点五，大概一成。

主持：一成，这也太低了。

解读：哺乳和爬行好一点，也不到两成。两栖、鸟和鱼都不到百分之五。

主持：我觉得关键不是低，是错得有规律。

解读：对。网上照片多的物种认得准，新描述的物种就难。有只豪猪，被叫成了已经废弃的旧名字。

主持：这跟大模型的老毛病一样，资料多的就会，资料少的就瞎猜。

解读：而保护工作恰恰最在乎那些稀有的、冷门的物种。

主持：所以研究者也没说别用 AI。

解读：他们的建议是，AI 先过一遍，再对照最新分类和分布范围核查，拿不准的交给专家。

主持：还要允许它说，我认不出来。

解读：这一条我特别赞成。这次测试不许它拒答，结果硬猜，错的记录就可能混进数据库。

主持：有意思的是，另一个小实验正好能接上。

解读：是数祖先的那个吧。给大模型一个家谱数据，让它数某个人有几个祖先。

主持：只给数据错误很多，加上知识图谱和本体，才数对。

解读：本体就是一套把概念和关系定义清楚的规则。不过最强的模型，各种格式都能满分。作者也说这是刻意设计的个案。

主持：但道理是通的。冷门知识，光靠模型的记忆靠不住，得接上整理好的数据。

解读：所以像维基数据这种开放知识库，在 AI 时代反而更重要了。

    OpenAI 博客 · Sam Altman 转发

    OpenAI 的 Michael Bolin 详解 Codex 沙盒。默认的 workspace 配置允许改工作区里的文件，但 .git 和 .codex 目录只读（防止改 Git 钩子和配置）；可以广泛读取文件（编译器要用），代价是别处的敏感文件也可能被读到；默认断网，防止数据外传。

    文章坦承沙盒挡不住所有坏事：比如 agent 可以往被 Git 忽略的 node_modules 里塞恶意代码，编辑器保存时就会在沙盒外执行，所以还要靠训练和对齐。实现上，Codex 不把计算搬进虚拟机或容器，而是用每个平台自带的机制：macOS 用 Seatbelt，Linux 用 bubblewrap 加 seccomp，Windows 正在改用微软新发布的 MXC 库。

    网络限制靠一个共用的本地代理按域名规则放行，代理先判断域名是否允许再做解析，因为连 DNS 查询都可能泄露信息。新的 codex sandbox 命令可以把同一套沙盒用在你自己的工具上，比如给一个 MCP 服务器单独套一个权限配置。Sam Altman 转发了作者的介绍帖。
