## 安全：轨迹、扩展与「让攻击更贵」
- **Cursor 安全事件完整复盘：供应商钥匙 → 历史轨迹里的明文凭证 → 恶意 Claude Code 扩展** {#cursor-security-incident} [长文]：Cursor 发布 10 月 29 日安全事件的调查结果。起点在 Fireworks：攻击者拿到了 Cursor 发给 Fireworks 的访问密钥（Cursor 称该密钥由 Fireworks 泄露），从一个用于共享数据的只读存储桶里复制了数据，里面是有限的编码 agent 轨迹，大多来自 2025 年、未开隐私模式、Cursor 获准用于训练的会话。少量轨迹里有没脱敏的凭证，不到 0.01% 的客户 API 凭证外泄。攻击者用这些凭证进入 Cursor 使用的部分 SaaS 工具，接触到归档的非生产代码库、部分客服数据和邮件、使用指标和联系方式等。10 月 29 日，攻击者用偷来的凭证把恶意的 Anthropic.claude-code 扩展副本（2.1.312 和 2.1.313）放进了 Cursor 扩展市场的缓存，最多约 5000 名用户可能拿到，约 11 小时后被撤下；上游 Open VSX 从未有恶意版本，这也不是 Anthropic 产品的漏洞。Cursor 称 Cursor 应用、正式更新和发布签名密钥未受影响，最后一次攻击活动出现在 11 月 1 日且被拦截。补救包括：推理流量全部撤离 Fireworks、轮换所有内部凭证、重建扩展市场、给所有代码库加密钥扫描。Daniel Avila 的评论是：问题不在于保存历史轨迹，而在于没把它们和里面的密钥保护好。后续：接 10-29 Cursor 扩展市场恶意扩展事件。来源：[Cursor](https://cursor.com/blog/security-incident-update) · [Daniel Avila](https://x.com/dani_avila7/status/2121612394937917487)
- **Shopify Cyber Chaos Monkey：带内部知识的 agent 在生产环境做受控攻击，另派一个 agent 当裁判** {#shopify-cyber-chaos-monkey} [长推]：Shopify 工程博客介绍内部系统 Cyber Chaos Monkey，名字致敬 Netflix 的 Chaos Monkey。理由是前沿模型让发现漏洞越来越便宜，Shopify 漏洞赏金的报告量自 2024 年以来增加了近 300%，他们决定抢先找。进攻 agent 手里有源码、威胁情报、历史报告和真实测试店铺的凭证，向线上系统发真实请求；隔离层包括每个任务一个独立的 Kubernetes Job、无提权容器、凭证代理和出口白名单；另一个用不同提示和不同模型的「裁判」agent 实时读日志，发现危险行为就终止任务。Shopify 称已执行上万次进攻任务，发现并处理几十个有实际影响的问题，没有造成停机或事故。来源：[Shopify Engineering](https://shopify.engineering/cyber-chaos-monkey) · [meng shao](https://x.com/shao__meng/status/2121438053755683224)

## Agent 与开发工具
- **Anthropic《Building always-on agents》：始终在线 agent 的五个部件** {#claude-always-on-agents} [长文]：Anthropic 应用 AI 团队的 William Hu 在 Claude 官网发布指南。核心观点：「始终在线」只是体验，agent 大部分时间在休眠，被事件唤醒跑一次（run）再睡。五个部件：事件收件箱（所有来源先把事件写进持久化列表，由一个 worker 领取，同一收件箱同时只有一个活跃 worker，连发的消息合并成一次运行）；计时器（跟进和日程两类，由调度器轮询到期项再往收件箱加事件）；记忆（只存以后查不到的东西，别处已有的只存指针）；权限（凭证由 agent 环境外的代理注入，高风险动作用自动模式的分类器审，重要决定用「延迟工具调用」等用户批准）；发件箱（控制什么时候开口，建议「先安静，再逐步赢得用户注意力」）。文中称在一项长周期编程基准上，Opus 5.5 每个解决任务的成本比 Opus 5 低 78%（Anthropic 自报）。meng shao 评价这些部件「单独看都不新」，价值在于职责划清；宝玉做了一期中文讲解。宝玉另发帖讨论交互形态：只有一个主会话，子任务不透明；一堆 Session，人又得自己记住谁在干什么，理想是人只盯主会话、由协调器判断消息归属，但每个任务都能点开干预。来源：[Claude 官网](https://claude.com/resources/articles/building-always-on-agents) · [meng shao](https://x.com/shao__meng/status/2121427594260398327) · [宝玉](https://x.com/dotey/status/2121406975279792268) · [宝玉（主会话与 Session）](https://x.com/dotey/status/2121434782433190063)

## 模型、训练与研究
- **Thinking Machines：端到端 4 比特训练，Inkling 2 Small 预训练只用 68 小时** {#tml-4bit-training} [长文]：Thinking Machines Lab 公开训练 Inkling 2 Small 的低精度方案：混合专家层的前向计算用 NVFP4（4 比特），反向更新用 MXFP8（8 比特）并配合重新量化和随机舍入来压低梯度偏差，GPU 间通信也做了量化；从预训练到最后一轮强化学习用同一套数值配置，训练完不需要再单独做量化校准。他们称这是已知最大的、前向全程用原生 4 比特训练的模型；在最大规模的任务上，比全程 MXFP8 预训练快 8%、强化学习快 20%。专用内核代号 BBBK。文中还提到，几个月前同等规模的模型要训练好几周，Inkling 2 Small 在 GB300 NVL72 机柜上 68 小时完成预训练，但这是多项改进叠加的结果，数值方案只是其中之一。来源：[Thinking Machines](https://thinkingmachines.ai/blog/end-to-end-4-bit-training/) · [Gorden Sun](https://x.com/Gorden_Sun/status/2121594565857878212)
- **Infrathon：给 agent 24 小时优化 AI 基础设施，排名会随时间变化** {#infrathon} [长推]：Ai2、华盛顿大学等发布 Infrathon 基准：6 个模型、150 次运行、每次 24 小时预算，合计超过 1 万 GPU 小时。150 次里有 135 次在后半段还在继续改进，模型排名也随评测时长变化，说明短评测会漏掉增益。在 KV 缓存压缩任务上，Claude Opus 5.5 把平均压缩指标从人类设计方案的 6.82% 提到 19.86%。轨迹分析发现的主要障碍是违反任务规则、测试不可靠和过早宣布完成。来源：[论文](https://paperswithcode.co/paper/2611.11995) · [HuggingPapers](https://x.com/HuggingPapers/status/2121515797671768333)
- **英伟达 cuPhoton：GPU 做黑洞干涉测量，10TB 数据 70 秒处理完** {#nvidia-cuphoton-eht}：英伟达技术博客介绍 cuPhoton.xBeam：事件视界望远镜把全球 13 个射电站的信号联合成像，xBeam 在 GPU 上把每对望远镜的信号相关成「可见度」数据，供后续校准和成像。团队与哈佛-史密森天体物理中心、MIT 干草堆天文台合作；在 64 块 GPU 的 Vera Rubin NVL72 系统上，10TB 数据 70 秒处理完，约为 x86 CPU 基线（8.89 小时）的 460 倍。来源：[NVIDIA 技术博客](https://developer.nvidia.com/blog/run-gpu-powered-black-hole-interferometry-with-nvidia-cuphoton/)
- **论文速递：AI 布线电路板、具身多 agent、流式视频生成** {#papers-1115}：PCBRouteAgent 让 LLM 做全局布线规划、由 KiCad 原生布线器执行，合成电路板上 100% 干净通过，真实子集上比基线最多高 36 分，不训练新权重。A2-MEAS 用代码作为扩展接口的具身多 agent 框架，在 12 个真机任务上成功率 57.92%，对比 pi0.5 的 26.67%。生数科技把 APEX 扩展到流式视频，少步生成，指令遵循的人类偏好比 S2-Avatar 高 30%。阿里 OneTrans-GSR 用一个自回归策略端到端生成推荐曝光列表，线上人均 GMV 提升 2.63%。Budget3D 可在任意 token 预算下从图像生成 3D。来源：[PCBRouteAgent](https://x.com/HuggingPapers/status/2121576383591661613) · [A2-MEAS](https://x.com/HuggingPapers/status/2121455383755817113) · [Condition Shifting](https://x.com/HuggingPapers/status/2121397194989453409) · [OneTrans-GSR](https://x.com/HuggingPapers/status/2121636326432964674) · [Budget3D（AK）](https://x.com/_akhaliq/status/2121393022353215679)
