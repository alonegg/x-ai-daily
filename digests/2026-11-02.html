  • #DeepSeek Super-agent 后续：李博杰逐条点评，英文版发布后续长推
    李博杰 · Gorden Sun · 向阳乔木 · tianyi（宝玉转发）
    前情DeepSeek Harness 团队发布 Super-agent 设计，Router/Worker 双层、事件驱动、云端常驻。 接 11-01 ↩

    李博杰说 dsh-superagent「非常赞」，分六点评论。一是 Router-Worker 实现 sessionless，难点在「活人感」：有事及时响应、说话简洁、没事少打扰；他 2025 年在 Pine 做个人 agent 时，用户抱怨 agent 啰嗦、干活时不理人，于是用了前台 agent 沟通、后台 agent 干活的结构，并说 Router 要懂不同渠道（电话、短信、Web、邮件）的信息密度。

    二是事件驱动：dsh-superagent 按数据源把事件组织成 thread，每个 thread 同时只有一个实例，不同数据源并行、同一数据源批处理，他比作 Linux epoll。三是异步 ReAct：耗时命令和子任务改成 start/stop，他说自己 2025 年初就提过这个思路。

    四是「脑手分离、存算分离」，harness 无状态，可在端侧也可在云上；他认为端云结合是最正确的设计。五是 Watchdog，他本地也有一个「监工」agent 处理 429 限流、崩溃和 VPN 故障。六是给上下文喂摘要和 ID、需要时再按 ID 读取细节，即渐进式披露。

    Gorden Sun 介绍原型 dsh-superagent-prototype：面向 GitHub 仓库，配飞书通知和网页面板，平时静默，有权限的成员派任务或触发规则时才开独立工作目录干活、提 PR，不需要人决策时不主动发消息。向阳乔木说「AI Agent 的下一个瓶颈就是人类自己」，一般人只能跟 3 到 5 个活跃会话，把 Grok Bot 的主 Bot、OpenAI Codex 的 Dots、Claude Code 的 Duet 和 Super-agent 归为同一方向。

  • #Armin Ronacher：agent 能重写 CPython，测试套件并非必需，以及「GPL 洗成 MIT」系列
    CPython · 参考 JVM · 测试套件 · readline

    Armin 说他确信现在可以让一个 Opus 5.5 agent 在大约两周内、无需人工输入、只对着测试重写整个 CPython，「可能」做到包括 ABI 在内的完全兼容、没有 GIL、带 JIT，并在所有可测指标上超过原版，「完全疯狂」；他补充说想试的人应让它参考 JVM 而不是 CPython 的设计决策。

    随后他回应很多人说的「价值在测试套件里」：重建一个东西并不需要测试套件，让 agent 为移植专门构建自己的测试可能更好，因为很多现成测试不利于「爬坡」；几周前他让 agent 重写 Excel 的公式引擎，测试套件也是它从零写的。最后他贴出一个例子：agent 先针对原版 readline 生成合成测试，再照着测试重写出 readline，他称之为「基本上就是一台 GPL 到 MIT 的洗衣房」。

  • #Anthropic 日合并约 3 万次：人审「证据包」；Daniel Avila 开自动合并长推
    meng shao · Daniel Avila

    meng shao 整理 Manish（kapmani）和 Addy Osmani 在 AI Engineer 的分享。Addy 称 Anthropic 日合并量从五月约 2500 提到约 30000：Claude 做首轮审查，并必须附上端到端、浏览器、lint、测试、截图或视频等证据，人审证据包而不是逐行读 diff；他强调只说「verify」太空，要落到端到端、property、视觉验证等具体测法才谈得上自动合并，Opus 5.5 已经够用，下一波收益在验证实践。

    现场举手几乎人人让 agent 开过 PR，真正每行人工看完的很少；CircleCI 说 CI 吞吐大涨，约三成合并尝试仍失败。框架是「软件产线」：亮灯工厂里人仍在规划、构建、检查、发布中做判断，黑灯工厂接近全自动，多数团队在中间，预计 2027 年底多数是「亮灯加若干暗角」。

    SonarSource 建议零信任，agent 环、CI 环、维护环各有独立验证，并用「导轨」把 agent 限制在批准路径上。责任仍在发起人，Manish 的总结是「写得快不等于发得快，自主权是挣来的」。同一天 Daniel Avila 说他正逐步在自己的仓库开启自动合并：Claude Code agent 处理 PR、CI 失败、安全扫描和 AI 代码审查（Cubic、Greptile、Claude Code review、NVIDIA Skillspector），所有检查通过即自动合并，敏感改动仍需人工批准。
