## Google：不生成文字的决策模型、AI 证明 Signal 安全、AlphaGenome 2

- **Gemini Decisions API 与 Gemini Decision 1：一次给上千个问题打分，输出 token 不收钱** {#gemini-decisions-api} [长文]：Google AI Studio 发布新接口 Decisions API，背后是新模型 Gemini Decision 1（`gemini-decision-1`）。它不逐字生成回答，而是在一次前向计算里给候选选项打分，返回概率和 0 到 1 的置信度，适合工具选择、策略检查、模型路由、内容分级这类「答案是封闭集合」的判断。一次请求可以放一份多模态输入（文本、图片、音频、视频、PDF，最长 256K token）加最多 1000 个独立问题，支持三种题型：是否题、2 到 255 个选项的单选、从 0 开始的有序评分。官方给的数字：模型计算中位时延 50–100 毫秒、端到端 150–250 毫秒，16K token 以内、每次 1 到 100 个问题时时延几乎不变；定价每百万输入 token 0.10 美元，输出 0 元，共享输入每次只计一次费；在官方自选的一组基准上「校准误差最低」，比用 Interactions API 调 Gemini 3.5 Flash-Lite 便宜近 5 倍。Google 内部用例：Gemini Notebook 用它做实时路由，日常问题时延最多降 40%；Stitch 用来快速生成可点线框；Google Labs 的 CC 从 200 多个表情里选回应；Google 搜索用它给 MCP 工具做对抗检测。OpenRouter、LangChain、Vercel、LiteLLM、Pydantic AI 等正在接入。Logan Kilpatrick 强调 API 可免费试用。后续：昨天 Hugging Face 刚定义「决策模型」接口，今天 Clem Delangue 转发 @LysandreJik 的消息称，transformers 里决策模型的批处理即将合入，提速最多 3–4 倍。来源：[Google AI Studio 长文](https://x.com/GoogleAIStudio/status/2120589299037147177) · [AI Studio 发布帖](https://x.com/GoogleAIStudio/status/2120581284690801060) · [示例应用](https://x.com/GoogleAIStudio/status/2120583393624698979) · [Logan Kilpatrick](https://x.com/OfficialLoganK/status/2120581433639198885) · [文档](https://x.com/OfficialLoganK/status/2120581534600343641) · [@LysandreJik（转发）](https://x.com/ClementDelangue/status/2120524332309020948)

- **AlphaProof Code：Google DeepMind 称首次把 Signal 协议形式化验证到生产代码层** {#alphaproof-code-signal} [长推]：Google DeepMind 宣布用新的 agent 式形式化验证框架 AlphaProof Code（运行在包括 Gemini Carbon 在内的大模型上），证明了 Signal 加密协议底层机器码的关键安全性质。官方说 Gemini agent 生成了 600 多万行 Lean 证明，人类专家只需审查其中最关键的 1%。带队的 Pushmeet（称这是「我在 Google DeepMind 的团队」）说，这是被广泛部署的协议的真实生产代码第一次在这个深度上被形式化验证（无论用不用 AI）；类似工作通常要团队累计几十年，他们用了一个月；形式化规格和验证产物将开源。需要注意：「证明安全」指的是被形式化的那组安全性质成立，结论边界取决于规格写了什么，外界复核要等产物公开。来源：[Google DeepMind](https://x.com/GoogleDeepMind/status/2120484246401777737) · [6M 行 Lean 证明](https://x.com/GoogleDeepMind/status/2120484249321033911) · [Pushmeet](https://x.com/pushmeet/status/2120127611137634376)

- **AlphaGenome 2：按单一细胞类型预测 DNA 变异的影响** {#alphagenome-2} [系列]：同一个人的心脏、大脑和免疫细胞 DNA 序列相同，为什么一个字母的变化只在某些细胞里致病？Google DeepMind 的 AlphaGenome 2 每次聚焦一种细胞类型，训练数据是 68 种组织、1 亿多份图谱；官方称它找到的「开关基因」突变数量接近上一代模型的两倍。它还能直接吸收实验数据而不用重训：输入几十个细胞的数据，就能看 DNA 变化在特定时刻（例如免疫细胞对疫苗的反应、肠道炎症、干细胞分化成血细胞）的作用。目前通过 API 和 Colab 教程向非商业研究开放。来源：[发布帖](https://x.com/GoogleDeepMind/status/2120532824465805749) · [训练数据](https://x.com/GoogleDeepMind/status/2120532826336501822) · [实验适配](https://x.com/GoogleDeepMind/status/2120532829805096970) · [开放方式](https://x.com/GoogleDeepMind/status/2120532832145576242)

## OpenAI：思维链越来越难监控

- **OpenAI 研究：模型越强，越难通过思维链监控** {#openai-cot-monitorability} [系列]：OpenAI 研究员 @jeffreygwang 发 10 条长推介绍新研究，看「思维链可监控性」在训练全过程中怎么变。两个代理指标：不写思维链也能推理的能力（越强越难监控），和按指令增删、操纵思维链的「可控性」。发现：在一批内部和已发布的前沿模型上，基础模型困惑度越低（预训练越好），不写思维链的推理能力越强，可控性也有较弱的同向关系；不同架构在多数评测上都能用困惑度预测，多跳规划和串行计算是例外；在 Astra 级模型的强化学习中，即使只有长度约束和最终答案评分，可控性也明显上升；可控性还能通过蒸馏从老师传给学生。但在两个能力相近、可控性不同的模型之间，没看到可控性与逃避监控之间有明显关联，作者因此称可控性只是对抗性规避的一个「有噪声的代理」。作者自己的定性是「不意外但令人清醒」。来源：[@jeffreygwang 线程（OpenAI 转发）](https://x.com/jeffreygwang/status/2120581630196879460) · [RL 阶段](https://x.com/jeffreygwang/status/2120581643169902819) · [结论边界](https://x.com/jeffreygwang/status/2120581651269075371)

## AI 工程：agent 写代码，人守验收

- **Shopify：30 名工程师 12 周用 agent 把商家 App 重建为原生** {#shopify-reflex} [长推]：meng shao 整理 Shopify 工程博客：商家 App 从 React Native 重建为 Swift 和 Kotlin 原生，300 多个页面，大部分代码由 agent 写。关键在「怎样快速可靠地检查对不对」：内部架构 Reflex 让两端结构一致，命令行工具不开模拟器就能跑业务逻辑，仓库规则偏离就报错；详细规格很快过时，最后改为把旧 App 当参照，由内部工具 Helix 拆成小步骤并对照验收。约 30 人两人一组，每人同时指挥多个 agent，每个 PR 仍由人审；崩溃监测每 15 分钟一次，Slack 里的 agent 能复现问题并提修复 PR。Shopify 自报：Android 启动中位数从 1.71 秒降到 0.87 秒，安装包从 80.4MB 到 47.6MB，内存中位数从 470MB 到 200MB；iOS 峰值内存中位数从 730MB 到 190MB；Android 无崩溃会话从 99.66% 升到 99.98%。来源：[meng shao](https://x.com/shao__meng/status/2120335490524365241)
