  • #IBM Granite LLMON：给模型用的标记语言，专治间接提示注入长文
    Hugging Face 博客

    IBM 在 Hugging Face 发布 LLMON（LLM Object Notation），把上下文里的指令、数据、要求拆成带保留特殊 token 定界的块，再用一个 exec 块写明「执行哪条指令、作用于哪段数据」，没被引用的块一律不执行。

    配套放出基于 Granite 4.1 的 3B 和 8B 实验预览模型。IBM 称在 OPI 基准上几乎消除了间接注入，比测试中最好的闭源模型多挡住 47% 的攻击、比最好的开源模型多 95%，通用能力与 Granite 4.1 Instruct 持平；但这是学出来的行为而非强制保证，目前只针对静态注入，多轮自适应攻击仍在改进。

  • #Claude Meetings：把 Claude 拉进 Google Meet长推
    Claude · 宝玉 · Daniel Avila

    Anthropic 推出 Claude Meetings 测试版，Claude 以参会者身份进入视频会议，边听边写纪要、回答问题，并当场起草文档、画白板，同事可同步修改；喊一声「Claude」或在聊天框打字即可提问，答案贴在会议聊天区。目前只支持 Google Meet，正向 Team 和 Enterprise 逐步开放。

    据宝玉整理：会后纪要、转录稿和会上产物放在该场会议页面；只存转录、摘要和屏幕内容的文字描述，不存音频；有外部人员加入时它会自动离开；测试期内纪要和问答不另收费，会上产物免费到 2027 年 2 月 10 日，调用已连接工具则计入个人用量；开了零数据留存、HIPAA 或客户自管密钥的组织暂不能用。

    宝玉指出一处不一致：发布文章说默认不进有外部人员的会，帮助中心却写 Team 默认「允许」，管理员最好自己核对。Claude Code Templates 作者 Daniel Avila 希望它从第一天就支持 OpenTelemetry 和合规 API。

  • #自托管 Claude Managed Agents 私测长文
    Claude 官方文章 · ClaudeDevs · ClaudeDevs 视频

    Managed Agents 现可整套运行在企业自己的云或机房：agent 主循环、沙盒、凭证和会话历史都由企业托管，模型请求可发往 Anthropic、Bedrock、Google 或微软的平台，或自建网关。官方文章强调四条设计：主循环与沙盒分离、凭证不进沙盒（由沙盒外代理注入）、按主机白名单限制网络、每一步都留记录并可通过 OpenTelemetry 导出。
