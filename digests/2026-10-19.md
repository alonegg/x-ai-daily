- **Harness²：Google 开源递归式 agent harness 优化框架，不改权重最高 +11.5 分** {#harness-squared} [长推]：昨天的 HF 论文速递简单提过 Harness²，今天 meng shao 和 Gorden Sun 做了详细解读。它要解决两个难题：测试时遇到的是没见过的任务、没有标准答案验证器；递归自我改进通常只对特定任务有效，换个任务就失效。第一层是任务级的「Propose–Probe–Compose」：先跑一遍当前 harness 拿参考轨迹，分别针对通用 agent 缺陷（规划、工具使用、上下文管理、委派）和领域知识/流程提出两个候选的文件级编辑；在同一任务、同样条件下执行，与参考执行做行为对比（论文强调这只为组合提供信息，不验证正确性）；最后基于证据合并、修订、取舍。每个决定都必须对应一个具体观察，而不是假想的分数提升。第二层是 harnessing 级递归：每个任务结束后反思，把有证据支持的组件文件和教训写进按领域组织的持久库（附 EXPERIENCE.md），下一个任务仍从公共基础 harness 出发，但由库来引导，相当于「改进 harness 的 harness」也在被改进。可编辑组件共 8 个：系统提示词、护栏、记忆、工具指引、Skills、subagents、脚本、TypeScript 插件。结果（k=1，编辑器为 Claude Opus 4.8）：GLM-5 在 WorkBuddy-Bench 上 64.2→75.7（+11.5）、在 LAB 上 59.6→71.4；Gemini 3.5 Flash 提升 4–5 分。执行模型越弱获益越大；为 Gemini 精炼的 harness 迁移给 GLM-5，在 Code 子集上 +17.3，也比 Claude Code、Codex 的固定生产 harness 高 4.6–5.8 分；执行器自己当编辑器也能涨（GLM-5 在 LAB 上 +13.7）；去掉库会损失 3.1 分，库也能跨基准迁移。parallel 和 sequential 两种扩展方式从 k=1 到 5 都单调提升。来源：[meng shao @shao__meng](https://x.com/shao__meng/status/2111730826308452600) · [Gorden Sun @Gorden_Sun](https://x.com/Gorden_Sun/status/2111652432761786872)

## 开放知识体系与开放科学
- **CDL26：用 SPARQL Patterns 把临床试验 PDF 变成可信的知识图谱** {#sparql-patterns-cdl26} [长推]：Connected Data London 2026 预告 Semantic Arts 本体工程师 Doug Beeson 的讲座《Sparql Patterns for Connected Data》。背景是：机构依赖的大部分知识仍然锁在 PDF 和文本文档里，生成式 AI 能轻松抽出数据，却很难把它们连成人和其他 agent 都能信任的整体。Doug 认为缺的是「模式」：他今年为一项出了名的难活（把临床试验方案 PDF 转成 RDF）开发了 SPARQL Patterns，用纯 RDF 编码数据点之间的连接，让这些连接能和数据本身用同一套机制管理。这样 AI 就成了知识图谱的「事实生成器」，产出其他 agent 可以无歧义使用的神经符号数据。这套方法后来在临床试验之外也证明有用，可作为构建结构化数据转换流水线的模板。适合手里有大量非结构化或半结构化文档、用 LLM 抽取却发现结果难以关联和信任、想找到可重复方式填充知识图谱的人；讲座技术幻灯片不多，有一点 RDF 基础更好。时间是 11 月 11 日 17:10–17:30（伦敦），Rapid Insights 分会场。来源：[Connected Data @Connected_Data](https://x.com/Connected_Data/status/2111701592516812863)
- **开源小学知识图谱：1590 个概念、3221 条依赖，正逐个变成互动实验** {#primary-school-concept-graph}：Lionel Mora 团队 7 月开源了一张动态图谱，收录小学阶段孩子要学的全部知识：1590 个概念、3221 条依赖关系。现在他们正把每个概念做成孩子可以动手玩的互动实验，第一个是给 7 岁孩子的「热和水」，目标是把枯燥的课本变成可能因人定制的体验。Juan Benet 转发说「梦想成真」。来源：[Juan Benet @juanbenet](https://x.com/juanbenet/status/2111686269562716171) · [Lionel Mora @lionel_mora](https://x.com/lionel_mora/status/2111156593693794386)
- **Doris Tsao 团队预印本：意识的神经结构有意外发现** {#consciousness-preprint}：神经科学家 Doris Tsao 发布 bioRxiv 预印本（Janis Hesse 主导），称发现了意识神经结构中一个完全出乎意料的特点，推翻了几十年来对意识生物学基础的看法，让人们离「产生意识觉知的配方」近了一大步。Juan Benet 评论：很好奇有多少无意识的感官信息会一路进入我们的世界模型、情绪反应、记忆和决策，这也许能解释很多复杂行为。来源：[Juan Benet @juanbenet](https://x.com/juanbenet/status/2111950921261535376) · [Doris Tsao @doristsao](https://x.com/doristsao/status/2111316522098733078) · [bioRxiv 预印本](https://www.biorxiv.org/content/10.64898/2026.10.15.759299v1)
