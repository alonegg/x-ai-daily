- **《Codex 沙盒内部》：不用虚拟机，直接借用各操作系统的隔离机制** {#codex-sandbox} [长文]：OpenAI 的 Michael Bolin 详解 Codex 沙盒。默认的 workspace 配置允许改工作区里的文件，但 .git 和 .codex 目录只读（防止改 Git 钩子和配置）；可以广泛读取文件（编译器要用），代价是别处的敏感文件也可能被读到；默认断网，防止数据外传。文章坦承沙盒挡不住所有坏事：比如 agent 可以往被 Git 忽略的 node_modules 里塞恶意代码，编辑器保存时就会在沙盒外执行，所以还要靠训练和对齐。实现上，Codex 不把计算搬进虚拟机或容器，而是用每个平台自带的机制：macOS 用 Seatbelt，Linux 用 bubblewrap 加 seccomp，Windows 正在改用微软新发布的 MXC 库。网络限制靠一个共用的本地代理按域名规则放行，代理先判断域名是否允许再做解析，因为连 DNS 查询都可能泄露信息。新的 codex sandbox 命令可以把同一套沙盒用在你自己的工具上，比如给一个 MCP 服务器单独套一个权限配置。Sam Altman 转发了作者的介绍帖。来源：[OpenAI 博客](https://openai.com/index/inside-the-codex-sandbox) · [Sam Altman 转发](https://x.com/sama/status/2123177797665587644)
