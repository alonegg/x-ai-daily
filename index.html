开场与头条预告

主持：早上好，今天是十一月二十四号，星期二。这里是 X 每日 AI 播报。

解读：早。昨晚的时间线，基本被一个人刷屏了。

主持：对，头一件就是他。黄仁勋回到英伟达了，还是总裁加 CEO。

解读：离他辞职才十来天。董事会公告里还专门写了一句，听取过美国政府高层的意见。

主持：第二件，Anthropic 出了个 Claude Ship，让 AI 不光审代码，还能批准合并。

解读：这个我有话说。写代码的是它，审的是它，最后点头的还是它，独立性怎么算？

主持：第三件更玄一点。一个开源模型，自己写代码，改了自己的权重。

解读：而且真变好了。不过离网上说的无限自我进化，还差得挺远。

主持：后面还有 Meta 的 Alexandr Wang 谈超级智能，和一个开放科学的好消息。先过快讯。

快讯

主持：先说安全。OpenAI 和思科一起开源了一个叫 Shirudo 的工具，日语里是盾牌的意思。

解读：它解决的是补丁没打上那几天怎么办。让 agent 在 Linux 内核里挂一个临时的小拦截程序，服务不用重启。

主持：有实测吗？

解读：有个受控测试。Codex 写的拦截规则，挡住了针对 Elasticsearch 的一次漏洞攻击，服务一直在跑。

主持：拦截规则要签名、要人批准才能上，这点我挺放心。

解读：对，还用了 TPM 芯片记录装了什么、卸了什么。许可证是 BSD，谁都能拿去改。

主持：第二条，DeepMind 用好几队 Gemini 四的 agent，去优化量子算法。

解读：每个想法都先拿 Lean 做数学证明，验过了才算数。各队每四个小时开一次线上会，互相挑刺。

主持：结果呢？

解读：一个聚变相关的电路，成本降到原来的十一点八分之一。一个常用的反正弦子程序，快了两百九十倍。

主持：不过官方自己也说，这些还是超出第一代纠错量子计算机的能力。

解读：对，算法变便宜了，硬件还得追。Lean 库和验证过的解都开源了。

主持：第三条给开发者。Gemini API 现在能只读文件的一部分。

解读：比如一份大 PDF，你只要第三到第五页；表格只要某个区域；视频只截一段。只按看过的部分收钱。

主持：这对 agent 挺实用，先粗看文字版，再把关键那页放大看。

解读：而且不用在本地装一堆转换工具了。所有 Gemini 四模型都能用。

主持：说到 Gemini 四 Neon，DHH 用它把自己系统的开机时间砍了一半。

解读：他还在六台电脑上同时跑了一整天，额度都没用完。不过他也说，配套的工具还挺糙。

主持：有个规矩要注意。Theo 提醒，Gemini 订阅只能在 Antigravity 里用。

解读：用别人做的伪装插件接进去，有人说一次请求就被封号了。T3 Code 走的是官方那条路，所以没事。

主持：第四条，接着昨天的困惑度话题。微软跟进了。

解读：微软在 OpenAI 的评测集上，报了自己 MAI 二基座模型的数，零点八一九，跟 OpenAI 的 GPT 五点六 Sol 基座差不多。

主持：不过他们自己也说，各家分词方式不一样，以后可能得换个指标比。

解读：李博杰挺高兴，说这验证了他八年前的压缩即智能。但也有人写了一串帖子反驳，LeCun 转发了。

主持：第五条，循环结构又多一个。智谱发了 GLM 五点四。

解读：在原来的模型上让一些层反复跑，加深推理，还加了看图能力。订编程套餐的用户已经能用。

主持：有每周额度的用户，用五点四能用的量比五点三多一半。

解读：有意思的是官方另一条帖子说，API 要等安全评估后再开放。

主持：本地模型也有好消息。Inkling 二 Mini 在 Mac 上的内存，从四十六个 G 降到不到十个 G。

解读：是 Hugging Face 的人写了专门的苹果显卡计算代码，专家权重不用解压。十六 G 内存的笔记本，可能也跑得动了。

主持：还有两个讲记忆的模型。MemT 一点零 Pro，把聊过的东西存进模型内部的状态里。

解读：每条对话的记忆才四十八兆。不过同一底座配上外部检索，长记忆评测分数还是高一大截，内部记忆还替代不了检索。

主持：另一条是扩散语言模型。DiffuSpace 的 Clover，总参数三百五十亿，每次只动三十亿。

解读：它在 SWE-bench Verified 上七十三点六分，单块显卡每秒能出六百八十个 token。

主持：腾讯也发了两个。一个专做电商理解，一个是放在手机上的小模型。

解读：电商那个比它的 Qwen 三点五底座，在电商测试上高了三点九分。

主持：浏览器圈也有新闻。从零写起的浏览器 Ladybird，发了第一个 alpha 版。

解读：Simon Willison 试了，说很快，大部分网站都能正常打开。关键是他们十月让编码 agent 去补网页标准测试，一个月多过了七万五千多项，超过了 Safari。

主持：Theo 说他以前觉得这是最蠢的项目，现在 agent 改变了他的算账方式。

解读：一个小团队做浏览器引擎，以前确实不现实。

主持：再说两条工程博客。vLLM 测了，把 agent 的缓存直接放到固态硬盘上。

解读：吞吐跟放内存几乎一样，差距不到百分之一，但存一天的数据，便宜一大截。代价是硬盘写得多，磨损要算。

主持：Hugging Face 也发了长文，讲怎么做 agent 评测。

解读：这个我放到评论里细说，里面有个数挺吓人。

主持：最后几条短的。levelsio 的 AI 回复黑名单，被人用流量攻击了，他改成按用户 ID 拉黑。

解读：改名也跑不掉了。另外 OpenAI 推了个 OpenWorks，出钱请本地 AI 专家，免费帮小企业。

主持：还有斯坦福的 Yejin Choi 和 Carlos Guestrin，创办了新实验室 Noeri，融了一点一亿美元。

解读：他们主张很多小模型协作，而不是押一个巨无霸。好，进重点。

重点一：黄仁勋复职

主持：先把时间线捋一下。十一月十二号，黄仁勋辞去英伟达所有职务。

解读：起因是十月底纽约时报的报道，说美国情报部门认为，一名接近他的中国籍女子在给中国情报机构提供信息。

主持：中间他还承认了婚外情，又有报道说他和一名下属有私人关系。

解读：对，辞职那天，财务总监 Colette Kress 兼任临时 CEO。十七号董事长还说，不打算让他回来。

主持：结果美国时间二十三号，董事会全票通过，让他即刻复职。

解读：公告给的理由是，多次面谈之后，对他的坦诚和领导能力满意了。

主持：我最在意的是那句，听取了美国政府高层的意见。

解读：原话是据此确信，他回来不构成国家安全风险。一家上市公司把这句写进公告，挺少见的。

主持：那调查就不查了？

解读：还查。独立董事组成的委员会，会把针对外国情报行动的调查做完，他也表示配合。

主持：另外还加了新机构？

解读：新设了一个国家安全与出口管制委员会，只由独立董事组成。还要招一个首席合规官。

主持：我理解这是在给华盛顿一个交代：人回来了，但看管加码了。

解读：可以这么看。另一边，政治上的说法就热闹了。

主持：有快讯账号援引消息源，说特朗普和万斯把他看成开源模型的保护者。

解读：David Sacks 也说，英伟达是美国开源阵营的头号支持者，你不会想看到只剩 OpenAI 和 Anthropic 的垄断。

主持：所以这事儿，一下子变成了开源和闭源的站队。

解读：而且市场反应也很直白。好几个人注意到，那天美股普遍上涨，Anthropic 的股票却在跌。

主持：有人说英伟达盘前涨了百分之二十八，这个数我们没核实。

解读：李博杰倒是提过，复职前一个月，英伟达从高点跌了百分之二十七。

主持：我其实有点担心。政府意见能决定一个 CEO 回不回来，这个先例不太好。

解读：可我有点不同意。英伟达卖的芯片本身就受出口管制，国家安全本来就绕不开它。

主持：那也该是监管规则管，而不是看谁跟总统关系好吧？

解读：这个担心有道理。我只是觉得，公告至少把政府意见写出来了，比私下打招呼透明。

主持：透明是透明了，可外界没法核实那些意见到底说了什么。

解读：对，这块确实看不到。还有一点，调查没结束，后面要是查出东西，董事会就很被动。

主持：所以这事儿还没完，我们接着跟。

重点二：Claude Ship

主持：第二个重点，Claude Ship。先说它是干嘛的。

解读：你在 Claude Code 里打一个斜杠 ship，它帮你推代码、开合并请求、自己审一遍，再处理反馈和失败的测试。

主持：它其实是三个部分拼起来的吧？

解读：对。第一个是代码审查，已经正式上线了，可以选快速、标准、深度三档。

主持：第二个叫 PR Steward，像个管家。

解读：测试挂了、代码冲突了、有人提意见了，它去修。每次推送都留言说改了什么、怎么撤回。

主持：但它不批准，也不合并，这个设计我挺认可。

解读：批准的是第三个，Claude Approvals。团队把规则写成一个文件放进仓库，常规改动它可以直接放行。

主持：有点像更聪明的代码负责人名单。

解读：没错。特殊情况，它会要求人来签字。

主持：效果有数据吗？

解读：官方说，Claude Code 团队从六月到九月，合并的请求多了一倍多。

主持：质量没跟着掉？

解读：被回滚的比例反而降了四成以上。

主持：不过那是他们自己团队，而且审查只是流程里的一层。

解读：对，这个前提要记住。收费是按 token 算，管理员可以设每月上限。

主持：符合条件的企业客户，还能领至少一万美元额度。

解读：Boris Cherny 说，一年前模型已经写他全部的代码了，但发合并请求的速度没跟上。

主持：我的疑问在开头说过了。写的、审的、批的，都是同一家模型。

解读：我倒没那么担心。它审查时会对每个发现做对抗式复核，而且人可以写规则，决定哪些必须人看。

主持：可模型的盲点是系统性的。它写的时候想不到，审的时候大概率也想不到。

解读：这点我同意。所以官方自己建议，先用只观察模式跑，不让它真的卡合并。

主持：也就是说，先看它会批什么，跟人的判断对一对。

解读：对，Boris 也说先挑一个仓库试。我觉得那份规则文件才是关键，写得太宽，就等于没审。

主持：我还会加一条：涉及权限、支付、数据删除的改动，永远要人看。

解读：合理。这类改动错一次，代价远大于省下的那点时间。

重点三：模型自己改自己的权重

主持：第三个重点挺有意思。一个开源模型，自己动手改了自己的权重。

解读：是 UIUC、CMU、斯坦福等学校十一位研究者的论文，十一月十八号发在 arXiv 上。

主持：用的是 Qwen 三点五，二百七十亿参数那个。

解读：他们禁掉了所有训练工具，只给一块显卡，跑几个小时，让模型自己写 Python 改权重。

主持：它先得知道自己哪儿不行吧？

解读：对，它先复盘做题记录。发现问题不是不会算，写完的题九成六都对，而是爱钻牛角尖，话没说完就超长了。

主持：宝玉举的那个例子特别形象。

解读：一道数数题，它把同一句英文复读了五百四十九遍，直到卡死。

主持：那它怎么改的？

解读：就改了一处。四十八层里，控制旧信息消退快慢的那个参数，统一调高零点五。

主持：说白了，就是让它别老在原地打转。

解读：对。在四百九十道没见过的题上，没答完的比例从百分之三十三点六降到二十六点一。

主持：准确率涨了六点六个百分点。

解读：而且改动直接写进权重，以后用不用加提示，也不多花算力。

主持：还有个修复的实验，我觉得更惊人。

解读：研究者故意把第三十层一个矩阵弄坏，模型数学直接零分。只告诉它有数值坏了，它自己一层层查出来，把异常值压平了。

主持：修回来多少？

解读：数学恢复到三十三分，原版是五十八点五。看图测试从七点三回到七十点二，原版八十四点三。

主持：有人在转述时，把八十四点三说成修好后的分数，这个要注意。

解读：对，那是原版的成绩。还有个关键限制，宝玉专门提了。

主持：是说八轮都是从原版重新开始吧？

解读：对，不是改完再接着改。所谓八轮只升不降，其实是它撤回了五次失败，只提交了三次成功的改动。

主持：小模型呢？

解读：完全不行。二十亿参数那个，直接说自己改不了权重。

主持：九十亿那个呢？

解读：更惨，它往权重里乱加噪声，把自己从四十七点五分改成了零分。

主持：我觉得这其实是个好消息，说明这事有门槛，不是谁都能失控。

解读：我看法稍微不同。门槛在模型能力，而模型能力每半年就涨一截，今天的二百七十亿，明年可能就很普通了。

主持：那你觉得该担心？

解读：不是担心，是该提前定规矩。比如自我修改必须留记录，能回滚，还得在没见过的题上验证。

主持：这篇论文自己倒是做到了这几点。

解读：对，它是个干净的起点。不过只在一个模型家族、只在数学题上测过，也还没经过同行评审。

重点四：Alexandr Wang 谈超级智能

主持：接着说递归自我改进。Meta 首席 AI 官 Alexandr Wang 发了篇长文。

解读：题目叫超级智能正在到来。他把黎曼猜想被证明，当成一个转折点。

主持：他说话挺狠，说跟它比，造原子弹只算家庭作业。

解读：对，他说很多物理学家会同意这一点。他的主线是，模型已经够聪明了，缺的是各行各业的专门知识和做实验的条件。

主持：然后他说 AI 研究本身也会被自动化。

解读：对，生物、武器、经济这些研究，可能快到人类看不懂、管不住。

主持：但他的结论不是加速，是说社会不该把控制权交给 AI。

解读：他说很难控制一个比人强一千倍的系统，整个行业得换条路走。问题是，文章没说换哪条路。

主持：Juan Benet 就直接追问了：你具体设想的是什么？

解读：后来有人骂这是疯了，他回应说，这些话别的实验室负责人也说过，他想强调的是这条路不是必然的。

主持：他还举了 Meta 自己的例子？

解读：对，说为了安全把 Muse 的发布推迟了几个月，扎克伯格也呼吁各家把大部分算力用来服务用户，而不是自我改进。

主持：我有点不买账。一边全速往前跑，一边说别走默认路线，说服力有限。

解读：我倒觉得，一个大实验室负责人公开说不可接受，本身就有分量。别家员工也会拿这句话去问自己老板。

主持：可是没有具体做法，最后很容易变成一句表态。

解读：这个我认。另外数学圈也有不同声音，LeCun 转发了一个观点。

主持：说数学其实分两种活？

解读：对，一种是用现有方法证明猜想，一种是发明全新的数学领域，比如微积分、拓扑。前者 AI 能做不奇怪，后者才算真本事。

主持：Ethan Mollick 反过来说，别忘了 LLM 直到最近都不擅长数学。

解读：他还引了一个社科研究的盲评。专家给模型写的研究设计打分，比哈佛一位知名政治经济学家的论文还高。

主持：但整体贡献那一项，模型没占优。

解读：而且专家之间对贡献怎么打分，一致性只比随机好一点。这说明有些价值，本来就不好量。

主持：那我的结论是：技术执行，AI 进步很实在；提出好问题，人还占着位置。

解读：我会说暂时占着。至于能占多久，别太早下结论。

评论一：OpenAlex 开放作者贡献角色

主持：评论环节，先聊个开放科学的。OpenAlex 开始记录每位作者在论文里干了什么。

解读：用的是一个叫 CRediT 的标准，把贡献分成十四类，比如方法、数据整理、写初稿。

主持：他们的比喻挺好：电影片尾字幕会写每个人干了什么，论文为什么不能？

解读：现在大约三百万篇论文有了这类数据，完全开放，谁都能用。

主持：数据从哪儿来？

解读：主要是论文正文里的作者贡献声明。只有用了标准术语、每个角色都能对上署名作者的，才记下来，从不按署名顺序去猜。

主持：准不准？

解读：他们请了两家公司的模型各自读三百篇来对照，记下的角色九成九以上一致。

主持：我觉得这对评职称挺有用。做数据、做软件的人，终于有地方留名了。

解读：可我有点担心另一面。一旦这些角色进了考核，大家就会抢着往自己身上多挂几个。

主持：角色通胀？

解读：对。而且覆盖不均匀，二零二二年以后的文章，也才百分之七左右有角色记录。
