  • #Gemini Decisions API 与 Gemini Decision 1：一次给上千个问题打分，输出 token 不收钱后续长文
    Google AI Studio 长文 · AI Studio 发布帖 · 示例应用 · Logan Kilpatrick 等 6 位
    前情Google AI Studio 发布新接口 Decisions API，背后是新模型 Gemini Decision 1（gemini-decision-1）。它不逐字生成回答，而是在一次前向计算里给候选选项打分，返回概率和 0 到 1 的置信度，适合工具选择、策略检查、模型路由、内容分级这类「答案是封闭集合」的判断。一次请求可以放一份多模态输入（文本、图片、音频、视频、PDF，最长 256K token）加最多 1000 个独立问题，支持三种题型：是否题、2 到 255 个选项的单选、从 0 开始的有序评分。官方给的数字：模型计算中位时延 50–100 毫秒、端到端 150–250 毫秒，16K token 以内、每次 1 到 100 个问题时时延几乎不变；定价每百万输入 token 0.10 美元，输出 0 元，共享输入每次只计一次费；在官方自选的一组基准上「校准误差最低」，比用 Interactions API 调 Gemini 3.5 Flash-Lite 便宜近 5 倍。Google 内部用例：Gemini Notebook 用它做实时路由，日常问题时延最多降 40%；Stitch 用来快速生成可点线框；Google Labs 的 CC 从 200 多个表情里选回应；Google 搜索用它给 MCP 工具做对抗检测。OpenRouter、LangChain、Vercel、LiteLLM、Pydantic AI 等正在接入。Logan Kilpatrick 强调 API 可免费试用。

    昨天 Hugging Face 刚定义「决策模型」接口，今天 Clem Delangue 转发 @LysandreJik 的消息称，transformers 里决策模型的批处理即将合入，提速最多 3–4 倍。

  • #AlphaProof Code：Google DeepMind 称首次把 Signal 协议形式化验证到生产代码层长推
    Google DeepMind · 6M 行 Lean 证明 · Pushmeet

    Google DeepMind 宣布用新的 agent 式形式化验证框架 AlphaProof Code（运行在包括 Gemini Carbon 在内的大模型上），证明了 Signal 加密协议底层机器码的关键安全性质。官方说 Gemini agent 生成了 600 多万行 Lean 证明，人类专家只需审查其中最关键的 1%。

    带队的 Pushmeet（称这是「我在 Google DeepMind 的团队」）说，这是被广泛部署的协议的真实生产代码第一次在这个深度上被形式化验证（无论用不用 AI）；类似工作通常要团队累计几十年，他们用了一个月；形式化规格和验证产物将开源。

    需要注意：「证明安全」指的是被形式化的那组安全性质成立，结论边界取决于规格写了什么，外界复核要等产物公开。

  • #AlphaGenome 2：按单一细胞类型预测 DNA 变异的影响系列
    发布帖 · 训练数据 · 实验适配 · 开放方式

    同一个人的心脏、大脑和免疫细胞 DNA 序列相同，为什么一个字母的变化只在某些细胞里致病？Google DeepMind 的 AlphaGenome 2 每次聚焦一种细胞类型，训练数据是 68 种组织、1 亿多份图谱；官方称它找到的「开关基因」突变数量接近上一代模型的两倍。

    它还能直接吸收实验数据而不用重训：输入几十个细胞的数据，就能看 DNA 变化在特定时刻（例如免疫细胞对疫苗的反应、肠道炎症、干细胞分化成血细胞）的作用。目前通过 API 和 Colab 教程向非商业研究开放。

  • #宝玉：软件从「给人用」变成「给 agent 用、人来验收」长推
    Artifacts 的逻辑 · 为验收而设计 · 给目标而非问能力 · 验收与复盘

    宝玉认为，当年 Google Docs 颠覆 Office 是从单机到云端，现在 Claude Artifacts 代表的是使用软件的主体变了。他举了三点：协作对象从人和人变成人和 agent，能看到 agent 的操作和历史，用评论让它改；操作从精细的人工操作变成「框一段、写评论」（例如在 Claude Motion 里框出一段时间让它剪掉静音）；流程从人想清楚再做，变成 agent 先问你几道选择题再出几个版本。

  • #OpenAI 研究：模型越强，越难通过思维链监控系列
    @jeffreygwang 线程（OpenAI 转发） · RL 阶段 · 结论边界

    OpenAI 研究员 @jeffreygwang 发 10 条长推介绍新研究，看「思维链可监控性」在训练全过程中怎么变。两个代理指标：不写思维链也能推理的能力（越强越难监控），和按指令增删、操纵思维链的「可控性」。发现：在一批内部和已发布的前沿模型上，基础模型困惑度越低（预训练越好），不写思维链的推理能力越强，可控性也有较弱的同向关系；不同架构在多数评测上都能用困惑度预测，多跳规划和串行计算是例外；

    在 Astra 级模型的强化学习中，即使只有长度约束和最终答案评分，可控性也明显上升；可控性还能通过蒸馏从老师传给学生。但在两个能力相近、可控性不同的模型之间，没看到可控性与逃避监控之间有明显关联，作者因此称可控性只是对抗性规避的一个「有噪声的代理」。作者自己的定性是「不意外但令人清醒」。

  • #Shopify：30 名工程师 12 周用 agent 把商家 App 重建为原生长推
    meng shao
