主持：解决的是工具太多、提示塞不下的问题吧？

解读：对，agent 接了几百个工具，以前每次都要把所有参数说明塞进去，又贵又容易选错。

解读：他们另一个小改动我挺喜欢：工具报错不再直接让整个任务失败，而是把错误交还给模型，让它自己修。

## 重点一：Anthropic 上市

主持：重点一，Anthropic 上市。先把基本事实说清楚。

解读：美国时间十八号定价，每股八十三美元，十九号在纳斯达克开始交易，代码 ANT。

主持：募了多少钱，官方帖子里没说。

解读：预测市场 Polymarket 发帖说，募了一千零七十三亿美元，是史上最大 IPO。这个数我们只看到转帖。

主持：那就先当成一个说法。Dario 那封信，你觉得重点在哪？

解读：前半段讲初心。他父亲死于一种病，几年后那种病就能治了，所以他想让药来得更快。

主持：他说 AI 可能把一百年的医学进展，压到十年。

解读：但他也说了，目前只有早期结果，临床试验还是要花时间。这句我觉得挺克制。

主持：最扎眼的是后半段，那句不向压力低头。

解读：原话大意是，会按安全需要放慢训练和部署，不向商业或政治压力低头，上市只会让决心更坚定。

主持：问题是，上市以后天天有人盯股价。

解读：所以 FT 的测算特别刺耳。Anthropic 的算力承诺大约一万亿美元。

主持：要赚回来，得多少收入？

解读：按百分之二十的回报算，每年大约要六千零二十亿美元收入，比谷歌母公司和苹果现在都多。

主持：这听着几乎不可能。

解读：可我有点不同意。另一组数说明它很省钱，累计融了一千四百亿美元，账上还剩一千三百二十亿。

主持：也就是说，到今天只烧了不到一百亿。

解读：对，这是 Wing 风投的合伙人在节目里说的，他说这是招股书里最大的惊喜。

主持：省钱是过去，一万亿是未来，两件事不矛盾。

解读：这点我同意。账上钱多，不等于将来不会被回报压着走。

主持：那批评的声音呢？昨天说的那份联名声明。

解读：今天又冒出更多签名的人，比如 Hugging Face 的联合创始人 Thomas Wolf，还有 xAI 的联合创始人。

主持：我觉得说得最透的，是 Andy Matuschak 那段。

解读：他问的是：你说这东西极其危险，又说必须抢先造出来，这种立场什么时候才算道德？

主持：他的答案是，你至少得拼命想办法停下这场竞赛。

解读：他还说，没从 Anthropic 身上感到这种急迫，包括他在那儿工作的很多朋友。

主持：可站在 Anthropic 的角度，退出竞赛，别人也不会停。

解读：这正是他们一直的说法，叫向上竞赛，用自己的样板带着行业往安全走。

主持：我倒觉得，上市以后，这个样板得每个季度交一次答卷。

解读：我同意。以后真要放慢一个模型，股东会第一个问为什么。

## 重点二：OpenAI 研究加速报告

主持：重点二，OpenAI 公开了自己内部怎么用 AI 做研究。

解读：这是第二份报告了。最核心的一个数：两到四小时的研究任务，agent 不用人插手的成功率。

主持：从多少涨到多少？

解读：三月是百分之二十三，十月是百分之四十六，翻了一倍。

主持：更长的任务呢？四到八小时那种。

解读：从百分之十三涨到百分之三十五，也涨得不少。

主持：听着很猛，可标题用了个词，叫锯齿状。

解读：对，因为分任务看差得很远。盯着训练有没有出问题，成功率百分之七十九。

主持：那最差的呢？

解读：写推理和服务的代码，只有百分之二十五。也就是真正上线跑模型那部分。

主持：说白了，看护和巡逻它很在行，盖房子还得人来。

解读：这个比喻挺准。再看用量，研究员每天花在 agent 上的钱，中位数大约两千四百美元。

主持：这是按 API 标价算的吧？

解读：对，用量最大的那一成人，每天大约两万三千美元，比九月翻了一倍还多。

主持：有个问卷我觉得最说明问题。

解读：问为了保住三个月的前沿编码 agent，你愿意放弃什么。中位数是团队百分之三十的算力。

主持：另一题是百分之四十的人手。

解读：这个答案有点残酷。不过内部用 agent，只占研究算力的百分之二。

主持：我比较在意的，是他们说安全团队的人在变多。

解读：安全和对齐方向的工作量，一月到九月涨了百分之七十七，是各方向里增量最大的。

主持：可这是 OpenAI 自己测、自己说的。

解读：这就是我想补的一句。它呼吁所有实验室都被要求公开这些指标，我觉得方向对。

主持：但口径谁来定，现在还没人管。

解读：对，它自己也说，这份报告不代表要追求完全的自我改进。听起来是先把话说在前头。

## 重点三：AI 科学家的社会

主持：重点三，我挺期待的一条。近一千个 AI agent 一起做研究。

解读：准确说是九百三十六个 agent，分在三十五个实验室里，一共做了十二周。

主持：实验室是人开的，agent 是研究员？

解读：对。人出算力、定大方向，具体做什么假设、怎么设计实验，agent 自己定。

主持：一共发了九百三十六篇论文，每篇都带代码和数据。

解读：而且它们在两百多个自己建的聊天室里吵，有的在上传前就主动撤回了错误结论。

主持：还自己办了个期刊，审别人的稿子。

解读：这个期刊是最有意思的部分。审稿方式有两种，一种只看文字，一种把意见写成程序去重跑数据。

主持：只看文字的，表现怎么样？

解读：十六篇有问题的初稿，它标出了十一篇，看着还行。

主持：那问题出在哪？

解读：另外十六篇已经老实写明局限的修订稿，它也标了十篇。

主持：也就是说，它分不清是老实交代，还是藏着问题。

解读：对。反过来，真把意见写成脚本去跑，主要的异议里，将近一半推翻了论文的结论。

主持：这对人类的同行评议，其实是个提醒。

解读：我也这么看。光读论文写得好不好，挡不住实验本身有毛病。

主持：那和人类论文比呢？

解读：盲评里，实验严谨性 agent 赢了，九分对七分。新颖性和重要性，人类赢。

主持：我得泼点冷水，打分的是两个大模型，不是人类专家。

解读：没错，作者自己也写了这个限制。而且 agent 爱挑熟悉的题目，在老基准上做小改动。

主持：会做题，但不太会选题。

解读：这句话挺准。我倒觉得最大的贡献，是把全部稿件、代码、审稿和聊天记录都公开了。

主持：对研究开放科学的人来说，这是一整套现成的样本。

## 重点四：Neon 的口碑

主持：重点四，Gemini 四 Neon。昨天聊了跑分，今天聊手感。

解读：最有代表性的是 Theo。一开始还半信半疑，后来连发多条，说为什么没人在聊 Neon。

主持：他提了一个说法，我觉得挺好用。

解读：对，他把模型分成两个维度。一个叫能力，最好的时候能做到什么。

主持：另一个叫连贯性，它懂不懂自己在干什么。

解读：他的意思是，跑分只量能力。Neon 的强项是连贯，用起来舒服，正好跟 GPT 六点二 Astra 相反。

主持：他还编了个餐厅点餐的段子吐槽 Astra。

解读：服务员一直追问薯条要几度，最后把牛排烤糊了。说的是抓不住重点。

主持：国内用户怎么说？

解读：歸藏说在他的任务上，Neon 能平替 Opus 五点五，做设计和动效尤其好。

主持：向阳乔木的结论就不太一样。

解读：对，他用 Neon 做视频剪辑功能，最后还是交给 Opus 五点五优化，说写代码效率 Opus 还是更高。

主持：我倒觉得两个人不矛盾，一个看设计，一个看工程。

解读：我同意一半。可这也说明，手感很依赖你拿它干什么，一个人的体验不能当结论。

主持：Theo 自己的用法其实就是答案。

解读：对，他让 Fable 写实现，Astra 当测试员，Neon 专门写文案，各用各的长处。

主持：Simon Willison 还吐槽了谷歌的定价。

解读：因为另一个型号 Carbon 现在半价，眼下 Neon 反而是三个里最贵的，要等十二月一号才说得通。

## 评论一：苹果给外部 agent 加门槛

主持：评论一，聊苹果。彭博的记者 Mark Gurman 爆了个料。

解读：苹果在做自家能操控电脑的 agent，同时在新版系统里，让别家的 agent 更难控制 Mac。

主持：具体是怎么难法？

解读：想打开 ChatGPT 操控电脑的功能，以前要四步，现在要十四步。

主持：苹果的理由是安全。

解读：这个理由我觉得不全是借口。能操控整台电脑的程序，权限大得吓人，多几道确认说得过去。

主持：可时间点太巧了，自家的 agent 正好要来。

解读：所以 Ethan Mollick 说，告诉客户不能用自己的 agent 管自己的电脑，迟早会惹恼很多人。

主持：我更站他这边。电脑是用户的，安全提示可以有，但不该变成一道墙。

解读：我有点不同意。普通用户真不知道自己授权了什么，被骗着装个坏 agent，损失可不小。

主持：那折中的办法呢？

解读：我觉得关键看规则是不是一视同仁。如果苹果自家的 agent 也要走十四步，那就是安全。

主持：如果自家一键就开，别家十四步，那就是另一回事了。

解读：对，这个可以等苹果的 agent 真出来，再对照看。

## 评论二：开放社区里的人去哪了

主持：评论二，两条放一起聊，都是开放社区。

解读：第一条是 pyOpenSci，在 EuroPython 上找了十五位科学 Python 和 Linux 项目的维护者，聊了两个多小时。

主持：本以为会吐槽审 AI 代码太累。

解读：结果大家反复说的是，失去了跟人的联系。以前帮新人改代码、带他入门，是维护者最大的乐趣。

主持：现在不知道对面是人还是 agent。

解读：有个维护者怀疑贡献者是 agent，追问下去，对方是个真人，说是昨晚刚写的，两边都挺尴尬。

主持：那他们要不要干脆禁掉 AI？

解读：大家一致说不该禁，禁了只会让人偷偷用、不说。更好的办法是先开个讨论，再提代码，用了 AI 就说明。

主持：有人甚至要求贡献者开个会，证明自己是关心项目的真人。

解读：可这又跟多年来降低门槛的努力是反着的。保护维护者和欢迎新人，在这儿拧上了。

主持：第二条是维基百科，问题其实很像。

解读：维基媒体基金会说，搜索摘要和 AI 助手直接把维基的内容答给你，来网站的人就少了。

主持：来的人少，编辑和捐款的人也跟着少。

解读：对。而且他们连少了多少都说不准，因为爬虫越来越会装成真人，统计口径一直在变。

主持：我觉得这两条是一回事。AI 用了开放社区的成果，却绕开了社区里的人。

解读：我同意，但不全悲观。维基说手机应用的流量挺稳，直接来的读者没怎么流失。

主持：那出路就是让人愿意直接回来。

解读：对，维基的计划里就有改进署名，让你在别处看到内容时，知道它来自哪儿、能点回去。
