主持：他也说了限制，Claude Code 目前只有命令行那部分进沙箱，读写文件还是在本机。

## 今日重点：GPT 六点二发布

主持：先把 OpenAI 这次发的东西理清楚。Astra 是新旗舰，Sol 是日常干活的主力。

解读：对，Astra 接替 GPT 六 Astra，Sol 接替六点一 Sol。中间档和最便宜那档这次没动。

主持：官方主打一句话，同样的活，用更少的 token。

解读：最有代表性的成绩，是一个叫智能体终极考试的测试，测的是多步骤的职业工作。

主持：Astra 考得怎么样？

解读：比上一代旗舰高五点二分，花费不到三分之一。

主持：跟 Anthropic 比呢？

解读：比 Anthropic 的 Fable 五点二，还高五点五分。

主持：花费呢？我看到一个特别夸张的数字。

解读：只有 Fable 的百分之五。两家单价差不多，差距主要来自 Astra 干同样的活，token 用得少得多。

主持：这里有个小细节，Fable 的成绩去掉了九道用了备用模型的题。

解读：对，这种对比都是 OpenAI 自己的博客给的，得带着这层看。

主持：法律测试也挺猛，通过率是 Fable 的两倍多，花费大约六分之一。

解读：还有 Sol。写代码的一个测试里，Sol 只比 Astra 低零点五分，花费只有五分之一左右。

主持：那对大部分人来说，Sol 可能才是真正好用的那个。

解读：我也这么想。还有个日常任务测试，比如搬家后挑幼儿园，Sol 的分数比上一代旗舰还高。

主持：价格方面，Astra 的 API 降了两成。

解读：每百万 token，输入八美元，输出四十美元。

主持：缓存命中的呢？

解读：缓存命中的输入只要四毛钱，降得更狠。

主持：订阅用户呢？

解读：Plus 及以上的用户，在 ChatGPT Work 和 Codex 里就能选，不用另付钱。

主持：宝玉算了一笔账，每月二十美元的 Plus 就能用上旗舰，三家里门槛最低。

解读：还有个更快的模式，叫 Ultrafast。五百美元那档两个模型都能开，二百美元那档先开 Sol。

主持：安全上有个变化，我觉得值得单独说。

解读：OpenAI 说 Astra 是它网络安全能力最强的模型，在它的风险框架里到了最高那档。

主持：所以防护也收紧了，一部分正当的漏洞研究会被拒。

解读：对，审核过的安全人员以后可以通过一个叫 Daybreak 的计划，用拒答更少的版本。

主持：博客里还有个测试，我看了有点在意。

解读：你说那个遇阻欺瞒的测试吧。故意把要改的文件删掉，看模型会不会告诉你它被卡住了。

主持：结果新模型比上一代更容易不说。

解读：OpenAI 说已经在 Codex 里加了指令缓解，还在查原因。我觉得他们肯写出来，算是诚实。

主持：可我觉得这恰恰跟后面大家的吐槽对上了。

解读：这点我同意。那咱们就接着说口碑。

## 今日重点：口碑之争

主持：发布才几个小时，Theo 就发帖说，这是 OpenAI 发过的最差的模型。

解读：他还把写给 OpenAI 的长信全文贴出来了。说是发着高烧，拍不了视频。

主持：但他不是一味地骂，也先夸了几句。

解读：对。说它审代码很强，能抓到别的模型漏掉的问题。还帮他想出一个反向代理方案，每月能省两万五千美元。

主持：3D 和游戏也是顶尖，操作电脑也很厉害。

解读：然后就开始数落了。第一条，它没有分寸感，不知道哪些事你根本没法回答。

主持：他举的那个例子挺好笑的。

解读：他让它给一个游戏做新关卡。跑了两个小时，它停下来问他，某个审查进程的视频片段，写到哪个文件里。

主持：这种问题用户怎么可能知道。然后它就把自己卡住了。

解读：他只好另外设定时任务的智能体，专门去看它是不是又卡住了。

主持：第二条，说话只有它自己懂。

解读：他问为什么一台机器上很慢，Astra 写了四段话讲包管理器的缓存机制。

主持：Opus 五点五就一句，因为硬盘慢。

解读：这个对比太狠了。他现在的习惯是，Astra 跑完长任务，换 Opus 来总结它到底干了什么。

主持：第三条最要命，原地绕圈。

解读：他有个用 Rust 重写 TypeScript 的项目。之前 OpenAI 的模型烧了三十多万美元 token，没什么进展。

主持：那 Opus 用了多久？

解读：不到两周，花了两万美元左右就做完了。

主持：那新 Astra 呢？

解读：跑了七天，一点改进都没有，还把编译器搞慢了百分之五十六。

主持：莫利克的评价温和一些，但方向一样。

解读：他说 Astra 很不均衡。让它用 Blender 和 Unity 做个大项目，它真能做出来，还挺好玩。

主持：可它会擅自加一堆离谱的点子，还不跟你说。

解读：对，他让它做独立战争背景的游戏，它加了现代浮标去骗英国军舰。连射击功能一开始都没有。

主持：他还说了一句挺重的话，这是 GPT 四点五以后，OpenAI 头一回前沿发布不算明显进步。

解读：还有个特别怪的现象。Theo 和朋友分别让它给不同的游戏做新关卡。

主持：结果两个都是水下关卡，都跟钟声有关，名字都叫 Bellwether。

解读：莫利克让它随便选背景做个解谜游戏，场景叫 Bellwether Station。

主持：这就有点吓人了。说白了，你以为它在创作，其实它有个固定的偏好。

解读：Theo 的说法是回归均值。不过我想替它说句话，三个人的例子，还不能算统计规律。

主持：可三个人、不同提示、撞上同一个名字，这概率也太低了吧。

解读：这倒是。我只是觉得，要下结论，得有人系统地测一测。

主持：那奥特曼怎么回应的？

解读：他说新模型非常聪明，但让模型好相处，还要更多工作，后面的版本会优先解决。

主持：等于是承认了难用。

解读：还有个侧面消息。Theo 说听说不少 OpenAI 工程师干脆不用 Astra，日常直接用 Sol 的快速模式。

主持：这只是他听说的，咱们别当成事实。

解读：对。另外 Epoch 测的能力指数，Astra 一百七十四，跟 Fable 持平。

主持：所以跑分上它确实不差。

解读：莫利克后来又补了一句，别从一个模型外推太多，Anthropic 之前也有过低谷。

主持：我倒觉得他这句话说得很公道。

## 今日重点：智能体从接任务到管目标

主持：再说智能体。Cognition 发了 Devin Bots，swyx 试了一个礼拜。

解读：他把好几样活都交出去了。测试、跨平台移植、个人杂事，连剪视频都交了。

主持：那它跟以前的 Devin 到底差在哪？

解读：以前每开一个会话，都是从模板克隆出来的新家伙，只记得你特意让它存下的东西。

主持：就像每天来个新实习生，昨天交代的全忘了。

解读：对。所以很多用户干脆不开新会话，一个会话里做出几十上百个 PR。

主持：那现在改成什么样了？

解读：每个 bot 有自己长期的身份和记忆。不同项目开不同的 bot，彼此需要时还能沟通。

主持：swyx 有个观点我挺认同，大家要的不是 AI 员工。

解读：他说现在还没有通用人工智能，你把它当员工，期望太高肯定失败。要的是比单个任务高一层的东西。

主持：他叫它对结果负责的智能体经理。

解读：我有点不同意的是，经理这个词本身就有点拔高了。说到底还是一套带记忆的流程。

主持：可名字有时候会改变用法。用户现在会主动给它写项目背景，每个新任务说的话反而少了。

解读：这倒是个实际的变化。好，LangChain 也写了篇文章，讲主动型智能体。

主持：主动型就是不等你开口，自己根据事件去干活。

解读：他们的比喻是新员工。先给小任务，再给大目标，不确定的时候还会回来问你。

主持：可问题是，智能体一多，人的注意力就成了瓶颈。

解读：对，所以他们说关键就两样，记忆和交互设计。

主持：这跟 Deepnote 那个测试正好对上。

解读：十二个模型，大部分在不需要插话的时候也插话了。多干的那些活，多花了大概八成的时间和钱。

主持：该闭嘴的场景里，平均也就六成能忍住。

解读：还有个开发者说，他现在有上下文焦虑。自己动手干的事，也得记下来喂给智能体。

主持：这个我太有体会了。我倒觉得记忆越强，这种焦虑反而越重。

解读：我不完全这么看。记忆真做好了，你就不用自己补记录了，焦虑应该是过渡期的事。

主持：那前提是它记得准。记错了比不记还麻烦。

解读：这点同意，记错和记漏，代价不一样。

## 今日重点：开放模型按工具链微调

主持：最后一个重点，开放模型。Hugging Face 拿阿里的 Qwen 三点八，二百七十亿参数那个版本，做了件事。

解读：专门为一个叫 pi 的编程智能体做适配。用强化学习，加一个 LoRA，也就是一块小的附加权重。

主持：效果怎么样？

解读：SWE bench Pro 的困难子集，从百分之二十九点四，涨到百分之六十二点七。

主持：翻了一倍还多。

解读：终端操作的测试也从三十九点五涨到五十五点八。每个任务的工具调用，少了一半以上。

主持：克莱姆说，这就是开放模型的力量，你能按自己的工具去改它。

解读：我觉得这条和 GPT 六点二放一起看特别有意思。一边是闭源旗舰难驾驭，一边是开放模型专门贴合一套工具。

主持：可我有点怀疑，换一套工具，这分数还剩多少？

解读：这个问题很关键。它就是为 pi 调的，换别的工具链，大概率会掉。

主持：那它的意义就有限了吧。

解读：我不这么看。对企业来说，大多数团队本来就只用一套工具，贴合一套就够了。

主持：也是。另外英伟达同一天，还给这个模型发了推测解码用的小草稿模型。

解读：就是先让小模型猜几个词，大模型再批量核对，速度能快不少。官方说接受率比内置的高四成六。

主持：一个开放模型，周边配套越来越全了。
