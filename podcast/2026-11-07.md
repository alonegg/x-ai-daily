# 11 月 7 日 AI 播报

## 开场与头条预告

早上好，今天是十一月七号，星期六。这里是 X 每日 AI 播报，我们用接下来大约半小时，把昨天 AI 圈的事情过一遍。

先说今天最重要的三件事。

第一件，Thinking Machines 放出第二代模型 Inkling 2 Small。总参数大约五百九十四亿，每次激活大约十七亿。现在先在自家平台闭源可用，官方说完成外部安全测试后，计划下周用 Apache 许可开放权重。

第二件，Anthropic 连发两篇博客：一篇讲 Claude 怎么用「做梦」整理记忆；另一篇请来客座作者，谈 AI 开始帮科学家写、跑、改科学模型。同一天，Claude Code 的云会话也更省事了，会自动配依赖，密钥还不进模型。

第三件，Google DeepMind 说，人类引导的 AI 智能体，在遗留的一千零二十四位 RSA 加密上找到了两处弱点；同时强调，现在主流的二千零四十八位系统，不受这些具体攻击影响。论点是：进入 AI 辅助数学的时代，不能再只靠历史经验。

另外，评论环节我们会聊企业 AI 账单为什么用量涨、钱却不怎么涨，Muse 把旗舰能力稀释进默认产品到底意味着什么，以及开权重时间表该怎么听、怎么准备。

## 快讯

下面是快讯。后面重点和评论要细讲的几件事，这里先跳过，只说其余的新鲜事。

先看 OpenAI。它和一家做酶设计的公司 Ligo 合作，发布了 BioBasicsBench。里面有一百个来自真实湿实验的日常分析任务，测智能体能不能读原始数据、发现错误，以及证据不够时敢不敢说推不出来。官方把这件事同时挂到生物安全上：加速研究，先得把日常分析做对。和那些炫目的端到端发现论文相比，这个基准更土，也更接近实验室每天真正耗时间的地方。同一天，它还转发了前沿模型论坛的网络越狱评级框架一号版本。论坛说，不是所有越狱都一样危险，要用能力增益、能力范围、部署难度、发现难度四类分数定档，方便实验室和安全团队对齐优先级。公开征意见到十二月二十一号。

再看视频。昨天摘要里已经提过的 Gemini Omni 一点二 Flash，宝玉又补了一轮渠道和价格：最长大约十五秒带声音，相对上一版便宜大约三成，七百二十皮大约每秒七美分，十五秒差不多一美元量级；开发者接口今天就能用，十二月三号起，旧版请求会自动切到新版。有中文博主体感画质大概是字节 Seedance 两成的九成，更快更便宜，但审核偏严，敏感词很多。

开源和训练工程这边。Hugging Face 团队据说投入大约八十万 GPU 小时，整理了一份混合专家模型训练手册，大约七万词，还配五十多个交互图和可跑代码，讲专家怎么选、跨卡通信为什么拖慢、路由和负载怎么稳。一位中文技术博主做了长编译，还提醒：部署时少选几个专家，不一定省显存；强化学习和推理引擎若路由不一致，训练出来的行为可能对不上。百度侧有人转发称 ERNIE 五点五 Flash 基座开源，大约二百八十亿总参、每 token 激活大约十四亿，细节以官方模型卡为准。

Shopify 工程博客介绍了 Reflex 架构：业务逻辑和界面分开，智能体用命令行读状态、发动作，不用开模拟器也能验原生应用行为。据说超过一千七百条行为测试，双端持续集成大约四分钟跑完；它不测像素，目前也还不是装完即用的开源库，团队要自己做适配层。另一篇工程速览讲 Uber 加速 Spark：计算侧用向量化引擎，写入侧评测商业引擎 Quanton，实验室数字很好看，但还不能直接等同生产收益。

Hugging Face 的克莱芒盘点开源机器人半年账：公开数据集大约近十万，涨了将近一半；模型大约超三万；自家两款开源机器人预计年末销量五万台以上，已发货两万多；乐机器人框架下载超一百万次，新版本带了世界动作模型和远程推理。他还强调：开源机器人意味着学生和创业公司能站在前人肩膀上，而不是一切锁进黑盒。

LangChain 本周很忙：深度智能体支持异步子代理，主会话可以边聊边等后台；浏览器工具测评里试了七套，Stagehand 胜出；LangSmith 自带云支持亚马逊、Azure 和谷歌云；Interrupt 大会订在明年三月底的旧金山。有人观察 Instagram 剪辑和 Roblox 工作室开始内置模型上下文协议，也就是让智能体直接动手、高手仍在熟悉工具里续作。

Connected Data 发文问：智能体到底需要什么样的本体。文章说，数据目录能标表的主人，却不能告诉智能体两条记录是不是同一客户；主张把「意思」和「事实」分开管，用构建环不断把数据变成受治理的知识，用查询环在每次请求时解释含义。伦敦那场 Connected Data 大会也只剩几天，亚马逊云还要讲开源的上下文本体加速器。

论文速递挑几条。Harness-S 用兄弟测试套件救援失败轨迹，再蒸馏回一个策略。Drex 是一类开放决策模型，一次前向就给出校准概率，不用自回归解码，有点像前几天提到的「只做判断题」路线。字节的 Cola 二据说用少得多的预训练量，在部分任务上超过 Llama 三的八十亿版。BestRand 想让基准压缩又稳又便宜。多轮强化学习的论文提醒：回合预算一紧，优势就会缩水。宝玉分享一个习惯：让智能体做完任务必须自测并截图，很多问题在截图时就会被它自己改掉。还有人继续推 Claude Code 的测试驱动开发钩子，从工具层拦住「没先写失败测试就改代码」。

社区侧，开发者 Theo 继续吐槽「怎么还没模型发布」，甚至怀疑某些推理轨迹读起来像量化开源模型，这是他的个人观察。另一位独立开发者继续清理社交平台上的 AI 回复垃圾号，说准备公开屏蔽列表，也要提交给别人的屏蔽合集。DHH 宣布他的 Linux 发行版 Omarchy 跑上了 Anduril 的 BlueChip 设备，靠的是对高通芯片的兼容工作；听写默认也和 Superwhisper 团队合作了好几轮。

最后是 Jupyter 和开放科学。JupyterHub 团队发了路线图复盘，基金会资助二月的研讨会之后，他们用类似二 i 二 c 的倡议仓库，现在有十一个开放倡议，还设了只负责状态是否属实的「倡议牧羊人」。QuantStack 发文：用网页蓝牙，在纯浏览器的 JupyterLite 里连乐高可编程砖，课堂可以不靠服务器扩到很多学生；架构上通用蓝牙管理和设备扩展分开，以后还能接辐射探测仪一类设备。伯克利数据科学研究所预告下周二有 Notebook.link 相关研讨。有人做了 JupyterLab 扩展 Nod，能从代码库任意位置跳进 notebook。多条安全聚合账号报告 JupyterLab 桌面版在某版本之前存在高危问题，写作时权威漏洞库条目还不稳，建议盯官方通告并升级。开放知识方面，彼得·苏伯等人推荐教科文组织新报告，谈开放科学落地时的学术传播公平，涉及文章处理费、评价、多语言和开放基础设施。还有开放科学静修营明年春天的申请窗口，以及公共科学图书馆创刊二十年的工具回顾。

## 重点一：Inkling 2 Small

接下来是今天的重点，一共六件。

重点一，Thinking Machines 的 Inkling 2 Small。为什么重要？因为一家强调「安全路径开权重」的实验室，又推了一代接近开放权重前沿的模型，并且把时间表说得很具体。

官方介绍：这是混合专家模型，总参数大约五百九十四亿，每次激活大约十七亿，支持看图，也可以调思考强度。在 Artificial Analysis 的智力指数上大约三十分出头，比上一代跳了一大截。现在先通过自家的 Tinker 平台闭源推理和微调；完成外部安全和红队之后，计划下周用 Apache 二点零许可放出全部权重。

能力演示偏 agent 和视觉：从零写城市模拟、在浏览器里启动 Linux、用三维软件做纸鹤动画，还有把平面图变成漫游。训练披露也不少：预训练大约八点四万亿 token，后面还有高质量续训；主强化学习大约一千零七十五步、一千七百多万条轨迹，任务从写代码到办公文档都有。中文圈有博主把它概括成「西方终于又有一个像样的开源候选」，但要注意：今天它还不是开放权重，开放要等安全流程走完。

我们的看法是：分数和排期都来自官方。等权重真的放出来，第三方复测和真实 agent 套件里的体感，才是更该看的。在此之前，把它当成「可试用、可微调、尚未自托管」更准确。也留意官方自己写的局限：它还不支持音频，聊天体验也不是优化重点，有时会话太多、组织不够干净。对要做语音助手的人，这不是今天的菜；对要做长时间编程和知识工作的人，才更对口。

## 重点二：Anthropic 的记忆做梦与科学建模

重点二，Anthropic 的两篇博客，外加 Claude Code 云环境。为什么重要？因为实验室开始把「记忆怎么整理」和「科学怎么建模」写成可复用的工程叙事，而不只是产品功能列表。

记忆这篇，把人类睡眠巩固记忆的分工，映射到智能体：交互时先记日志，空闲时再用所谓 dreaming，也就是做梦式整理，去纠错、写笔记、重组表征。灵感来自 Letta 和伯克利提出的「睡眠时间计算」。评测故事很具体：有的模型在玩宝可梦时疯狂建几百个记忆文件，有的更克制；还有人用大约三十五万个内部文件、四亿多 token 的语料，让模型在一百多个会话里用做梦建维基。文章也提醒，给太死的指令，比如「只记失败」，反而可能伤效果；弱模型有时需要被明确要求「先读记忆再答」，强模型则更常自己养成这个习惯。

科学这篇是客座文章，作者来自欧洲的 ELLIS 和图宾根大学。他们讲：科学家仍常手写模型，并在多种假说之间权衡；AI 开始把「写代码、跑拟合、再改模型」做成循环，探索数据到底支持哪种结构。开篇用霍奇金和赫胥黎当年手摇计算器解方程的故事，对比今天的节奏。

产品侧，Claude Code 云会话对专业档及以上更省事：它会推断依赖、网络和密钥需求并保存环境，密钥安全存放，模型看不到。社区则继续推测试驱动开发的强制钩子，也有人澄清：模型从仓库元数据「捡到邮箱」，多半是模型行为，不是客户端偷偷发信。

我们的看法是：做梦很迷人，但公开博客里的基准多半是自家设定；你真正该问的是，自己的 agent 有没有「空闲时整理」的固定工位，以及整理规则会不会把过时信息写死。科学建模那篇更像研究议程，而不是「今天就能替换实验室流程」的产品说明。两者合在一起，像 Anthropic 在同时打两张牌：一张面向编程智能体的工程记忆，一张面向科研合作的长期叙事。

## 重点三：DeepMind 压测遗留 RSA

重点三，DeepMind 的加密压测。为什么重要？因为它把「AI 加速科学」直接伸到了密码学假设上，同时又用很硬的边界，避免制造恐慌。

官方说法很清楚：人类引导的模型，在遗留的一千零二十四位 RSA 上发现了两处重大弱点；现代二千零四十八位及以上部署，不受这些具体利用影响。他们要强调的是节奏变化：过去靠历史硬度外推，以后要持续压测。二手报道还提到签名填充在攻击者可控比例升高时失效、以及相关模数批量分解更便宜等方向。那些细节以后续论文为准，我们今天只锚定官方主帖的边界。

把这件事放回本周语境里也很有意思：前一天 OpenAI 还在谈自主挖洞流水线和防御向模型；今天 DeepMind 谈的是数学侧的硬度假设。两边都在说同一句话：AI 改变的是日历，不是物理定律本身。

我们的看法是：对运维来说，行动项很朴素，清点还有没有一千零二十四位密钥仍在生产；对研究者来说，这是「智能体加速形式科学」的又一个样本。还有一层容易被忽略：官方反复强调「人类引导」。换句话说，不是模型自己半夜翻出漏洞，而是人设方向、人把关，模型负责加速搜索。这和完全无人值守的挖洞流水线，不是同一种风险故事。

## 重点四：Muse 专用模型与 Spaces

重点四，Meta 的 Muse。为什么重要？因为旗舰 Wonder 的能力，开始被蒸馏进更多人每天打开的默认助手。

亚历山大·王说，从昨天起，Muse 和 Meta AI 跑在用 Muse Wonder 训练的新专用模型上。研究博客给了几组对比：个人超级智能指数大约从三十八提到四十七；主动记忆评估里，正确使用关键上下文大约从七十六提到九十，并称关键信息遗忘大约降到原来的二点四倍分之一；主动专注下，遇到意外阻碍时完成日常任务大约提升百分之六十七。同时上线 Spaces：你用聊天描述兴趣，它生成一个空间，可以钉在导航栏里持续更新。

结合前一天 Muse 语音在美国全量开放，你会看到一条清晰产品线：先把旗舰做出来，再把记忆、专注、语音、空间这些能力，铺进默认入口。

我们的看法是：这些数字都是 Meta 自家评测。产品体验上更值得观察的是，主动记忆会不会记错「过期事实」，以及 Spaces 会不会变成又一层难清理的个性化缓存。若你同时用好几个助手，也可以问自己：愿不愿意把「跨天目标」托付给一个会主动继续干的系统；主动很香，越权也很麻烦。

## 重点五：开发工具链把验收留给人

重点五，开发工具链。为什么重要？因为编程智能体的瓶颈，正在从「会不会写」转向「环境能不能一次配好、结果能不能一次验完」。

Claude 官方说云会话会自动搞清依赖和网络，并把密钥存到模型看不见的地方。Shopify 让智能体不靠模拟器验行为。LangChain 让子代理在后台跑，主对话还不中断。创作者软件开始内置模型上下文协议。宝玉则把旧管理经验搬过来：以前要求同事提交变更必须带截图，现在要求智能体任务结束必须自测并出图。一位中文博主还提到，做 DeepSeek 相关插件时，连自动更新都得自己实现，说明「智能体生态」仍有大量胶水工程。

我们的看法是：自动化配环境很香，但也更需要审计「它到底申请了什么权限」。密钥不进模型是底线，不是加分项。验收截图看起来土，却往往比再写一段提示词更管用。工具链越完整，团队越要想清楚：哪些步骤允许全自动，哪些步骤必须留下人的签名。

## 重点六：JupyterHub 路线图与课堂机器人

重点六，Jupyter 社区。为什么重要？因为一边在补治理和可见性，一边在把 notebook 重新接到可摸到的硬件上。

JupyterHub 的路线图复盘写得很诚实：以前也有过路线图，但没人拥有、也嵌不进日常流程。现在用倡议仓库，故意保留「在做、规划、征反馈、明确暂缓」多种状态，并承认志愿者和付费贡献者之间的张力。有个成功案例是：服务器命名更严格的改动，因为上了路线图，被影响的用户提前看到，而不是等到发版才吓一跳。

QuantStack 则演示：在纯浏览器的 JupyterLite 里，用网页蓝牙控制乐高。对学校来说，这意味着扩到全国课堂，有时只是多发一个静态网站地址，而不是多租一批服务器。当然，蓝牙接口目前主要在 Chromium 系浏览器。安全聚合源同时在报桌面版高危问题，提醒我们：发行面一散，补丁节奏就要跟上来。

我们的看法是：路线图解决的是「别人看得见你在忙什么」；蓝牙机器人解决的是「小孩看得见自己的代码动起来」。两者都偏长期，但方向清楚。若你在学校或公益机构推计算课，纯浏览器加低成本硬件，可能比再申请一批云额度更现实。

## 评论一：企业 AI 账单用量涨、钱不动

进入值得评论。我们会讲清楚原帖说了什么，也会明确说出我们自己的判断。

评论一，企业 AI 支出。原帖是一位中文技术博主根据科技媒体和 Ramp 数据做的长整理。事实层面：从八月初到十月中，样本企业 token 用量大约涨了百分之六十五，花钱只大约涨了百分之一点五；七月支出还在猛涨，八九月几乎停住。解释包括大模型降价、把活路由到更小模型，以及只做「是或否」的决策模型更便宜。文中还提到，综合单价大约一个月里从每百万 token 七毛多降到五毛多。同一文还叠了 Anthropic 上市估值讨论下修、以及招股书里用量增长被折扣吃掉大约六亿美元的数字。样本偏美国、接入了 Ramp 相关工具的科技公司，不是全球普查，个人自费账号也不在里面。

我们的判断是：这更像「单价下跌追上用量上涨」，不等于 AI 需求见顶。对买方是好消息，对靠高价锁估值的卖方是压力测试。最有力的反对意见是：一旦出现下一代必须用旗舰模型的新场景，支出曲线可能再次陡起来。

给你一个具体建议：这周把团队默认模型档位和月度预算钉死，并单独留一笔「旗舰实验」额度，避免全员默认跑最贵模型。如果财务能导出 token 单价，不妨画一张「用量与支出」双轴图，看看自己是不是已经站在买方市场里。

## 评论二：记忆该记什么

评论二，Anthropic 的做梦记忆。原帖事实前面重点讲过：空闲时整理日志，评测里既有成功闭环，也有记太多、记太死的反例。

我们的判断是：记忆系统的胜负手，往往不是「能不能存」，而是「敢不敢忘」。过期的余额、临时的文件路径、一次性的错误猜测，都不该变成永久人格。最有力的反对意见是：没有记忆的智能体，每次都像失忆员工，长期任务根本做不完。

给你一个具体建议：给自己的编程智能体加一条规则：会话结束或空闲时，只允许写入三类笔记：可复用的项目约定、已验证的失败原因、以及明确标注日期的事实；其余一律不进长期记忆。一星期后抽查一次记忆目录，把过期条目删掉，比再买一个记忆插件更重要。

## 评论三：加密压测与防御窗口

评论三，DeepMind 与遗留 RSA。原帖事实：弱点落在一千零二十四位，二千零四十八位不受这些具体利用影响，但要求持续压测。

我们的判断是：这是「AI 缩短研究日历」的正面示范，也是对懒惰运维的提醒。最有力的反对意见是：公开讲弱点可能帮攻击者；但官方已经把范围钉在遗留参数上，并且现代部署不在冲击面内。

给你一个具体建议：今天花十五分钟，在证书和远程登录资产清单里搜一千零二十四，有就排期替换；没有就把「密钥长度基线」写进下一次安全评审清单。若你维护的是老设备或老支付网关，别假设「从没出过事」等于「数学上还安全」。

## 评论四：旗舰能力稀释进默认产品

评论四，Muse 的专用模型。原帖事实：Wonder 训练出来的能力，进入 Muse 和 Meta AI；遗忘下降、遇阻完成率上升，还有 Spaces。

我们的判断是：这是大厂经典路径，先做贵的旗舰，再蒸馏给海量默认用户。对用户好，对「只靠旗舰订阅差异化」的对手压力大。最有力的反对意见是：自家指数涨了，不等于你的真实任务变稳；个性化空间也可能让错误偏好更难纠正。

给你一个具体建议：若你日常用 Muse 类助手，这周故意测两件「跨天任务」：一件依赖它记住的约束，一件中途改需求，看它是衔接还是幻觉。测完把失败案例写下来，这比看官方指数更接近你的真实工作流。

## 评论五：开权重时间表与安全门

评论五，Inkling 2 Small。原帖事实：能力表很漂亮，但权重仍闭源，开放绑在外部安全测试之后，许可意向是 Apache。

我们的判断是：把「先可用、后开权重」说清楚，比空喊开源更负责任；也请读者不要把「计划下周开源」听成「今天就能自托管」。最有力的反对意见是：闭源窗口可能无限延期。原帖给了比较明确的下周意向，我们按字面记录，不做预测。

给你一个具体建议：若你关心开放权重，先把评测套件和微调脚本准备好，权重一放就能跑；在此之前，用官方平台做小规模试用不丢人。也可以同步关注安全报告：开放权重前后，攻击面评估往往会更新一轮。

## 收尾

今天的主线，是能力继续往下沉：沉进记忆整理、沉进默认助手、沉进课堂浏览器，也沉进对旧加密假设的压测；另一面，账单和开源时间表提醒我们，扩散不等于无限加价，开放也不等于立刻可下载。

若你只记住三句话：第一，空闲时整理记忆，可能和模型本身一样重要；第二，遗留密钥和遗留流程，往往比新模型更快变成风险；第三，买方市场里，先管住默认档位，再谈追旗舰。
