# 11 月 6 日 AI 播报

## 开场与头条预告

早上好，今天是十一月六号，星期五。这里是 X 每日 AI 播报，接下来二十多分钟，我们把昨天 AI 圈的事情过一遍。

先说今天最重要的三件事。

第一件，OpenAI 同一天放出两件硬货。一边是图像模型 Images 二点六，能出 SVG 矢量图和 GIF 动图，官方称 API 出图大约快一半；另一边是安全研究：一条自主流水线，以大约一百二十一万美金的 API 成本，复现一千七百多个漏洞，产出九百四十八个可用的 Linux 本地提权利用，并正式发布 GPT 六 Cyber。

第二件，人才与评估两条线同时动。前 Claude Code 产品负责人 Cat Wu，前天离开 Anthropic，昨天自己宣布加入 OpenAI，负责核心产品管理。独立评估机构 METR 则说，Anthropic 在目标明确任务上的能力进步速度大约翻了一倍，但约一百页完整报告里，大半最有说服力的证据被 Anthropic 涂黑了。

第三件，开源生态这边压力很大。Jupyter 安全委员会说，二零二六年已经收到一百八十一份安全报告，九月单月创纪录四十份，主因是 AI 生成提交。pyOpenSci 整理十五位科学 Python 和 Linux 维护者的焦点小组，大家更怕的不是审查变慢，而是「人消失」。

另外，评论环节会把人才流动、透明度、agent 自动打洞、维护者困境这几条，拆开细聊。

## 快讯

下面是快讯。后面重点和评论要细讲的，这里先跳过，只说其余的新鲜事。

先看产品和公司。Meta 的 Muse 语音模式，对美国所有用户全量开放了，随时可以语音或视频通话。有人说体验像 FaceTime，Meta 还会为每个自定义形象单独训模型。

Anthropic 在美国推出测试版个人理财。经 Plaid 只读连接自选银行和信用卡，可以问钱花哪了，但不能转账、管理或投资。只有美国的 Pro、Max、Ultra 个人订阅分批开放。独立开发者 levelsio 试让 Claude 经浏览器用 Revolut 自动付账单，被明确拒绝，官方说即使你已登录浏览器也不转账，是固定规则，不是技术限制。

谷歌宣布 Gemini Omni Flash 一点二：最长大约十五秒视频、更深镜头控制、多轮对话编辑，标价比一点一低大约三成，已在 AI Studio 和 Gemini API 可用。

再看开放权重。百度开源了 ERNIE 五点五 Flash Base，混合专家大约两千八百亿总参数、激活一百四十亿，自称同规模匹配前沿水平；完整 Flash 还在路上。一位中文技术博主提醒，对照表多是同参数量级的旧版，不是各家最新。Cognition 的 SWE 二 Flash，在 FrontierCode 二上成绩持平，却大约快三倍、便宜五倍，有人点评「没有权衡的蒸馏」，并称将通过安全项目向伙伴与研究者分享权重。Kimi K 三点一 Pro 和 Ripple 六点五 B 的余波还在继续。

开发工具这边。LangChain 大幅改进了托管深度智能体的异步子代理：编排器可以在后台子代理干活时继续回应用户。创始人 Harrison Chase 说，内部多数智能体已实质依赖它。有人举例子：在 Slack 让智能体比三家供应商，三个子代理并行调研，主代理仍能答追问。

证据文化后面重点细讲。先提一句：Anthropic 台上对谈说，每天合并次数已从五月大约两千五，涨到九月超过大约三万。

Notion 创始人文章里有一组数字：大约一半页面由智能体创建，今年站内 AI 使用量大约增九倍；第三方智能体用 Notion 存上下文，调用量大约增六十倍。组织上把设计、产品、工程合并成「building」。

社区与体验。levelsio 称已把《战地一九四二》移植到 iPhone 和安卓浏览器多人；Claude Code 自建图形层，把 Direct3D 指令译成 WebGL，又改引擎修竖屏界面拉伸。他还说即使开全防护，每天仍大约屏蔽五十个 AI 回复号，认为与允许 Grok 接管 X 账户有关；Paul Graham 转发观点说，社交网络不需要机器人，真人互动本就稀缺。

研究速递。斯坦福、麻省理工和牛津的协作智力基准：二百四十道可程序验证任务、八个协作维度，只在模型独自本就能解对的题上计协作分。默认设置下 Gemini 四 Argon 大约七十六点六，开最高推理后全场最高大约八十二点二。冲突维度里大约一成四谈成对团队最好的方案；约百分之四十五的失败，发生在模型已经识别问题之后。

英伟达等的 VFlash，对边界框、机器人轨迹这类固定长度浮点输出一次并行写出，避免自回归「写死无法回退」。称在边缘 GPU 上动作解码最高大约快十二倍，三维轨迹误差最高大约低六成一，论文和代码开源。

OntoSmith 用分层模型低成本建知识图谱：抽取用廉价中层模型，判断用小决策模型，前沿模型只留给真正难的案例。Lovable 架构复盘说，产品目标几乎没变，实现推倒重来多次，最终用一套框架对运行中整机做分支与合并；称代码库已合并超过十万个拉取请求、用户创建超过七千万个项目。

智能体工程还有几条。数据笔记本产品 Deepnote 说，多数把上下文层做起来的数据团队没买专用产品，而是写 Markdown 放进 git；一例称智能体准确率从大约一成四提到大约九成，搭建大约五分钟。一位中文技术博主分享逆向 Claude Design 技能包的技巧：不直接问系统提示，而让它先用该技能做一件最小作品，再要求「做一个输入输出一样的技能」，利用已加载上下文还原大意。做 Claude Code 模板的开发者说，外部技能可由作者托管自有 GitHub，经模板站分发，安装钉死提交、校验哈希并过安全检查，已有十一个外部技能。

机器人与视频论文也很多。Ai2 发布基于 Molmo 二的视觉语言规划器，简单仿真任务成功率大约九成七。清华和伯克利的 uni-robot-agent 框架续报，同一模型在 RoboDojo 上从大约一点九提到大约三十一。还有 GameVerse 游戏录像数据集、VideoMemBench 多轮视频对话评测、面向端到端物理研究智能体的 FrontierPhysics。斯坦福公开课整理了数据筛选与评测基准设计：生成轨迹已便宜，难在筛选；好基准要在难度、真实性和可运行性之间平衡。

开放知识。OKFN 宣布 Frictionless 的 R 和 Python 库全面支持 Data Package 二，并保持一代工作流兼容；Python 侧还修了安全公告，测试扩到两千三百多项。Wikimedia Enterprise 二零二五到二六财年净利润大约七百四十万美元，收入大约一千三百一十万，较上年明显增长，期末十六家付费客户，新公布含亚马逊、Meta、微软、Mistral、Perplexity。基金会审计连续第二十一年无保留意见；有文章指出小语种维基的「AI 隐形税」：印地语等非拉丁文字同义内容，token 大约是英语的两到三倍，小维基核心困境是人力而不是条目数。Mathlib 团队获 Demailly 数学开放科学奖；Helmholtz 设科研软件奖表彰「沉默的英雄」。

社会层面。沃顿教授 Ethan Mollick 转 Erik Brynjolfsson：美国上季度生产率年化大约百分之三点六，远超历史平均，或显示 AI 推动拐点；并称无论本次选举 AI 角色如何，未来选举都会更深卷入。编程博主 Theo 引媒体称，苹果在鼓励用 AI 的同时削减员工 AI 使用预算，日限额从大约三百美元降到二百甚至更低。安替转述新当选参议员的说法：对中国 AI 的逻辑是「我们慢下来，他们抄我们，所以也会慢」。路透：因中国未批进口，大量英伟达芯片积压香港。

## 重点一：Images 二点六，SVG 和 GIF 一起来

为什么重要？因为出图不只是更快，而是开始能直接进设计和表情包工作流。

OpenAI 前天发布 Images 二点六，ChatGPT 与 Codex 全档位，网页、桌面、手机都能用。API 同步推出两个版本：Flare 偏速度，低画质最快大约六秒出图；Sunburst 偏画质与连续编辑一致性。官方称生成速度比上一版快大约一半。

一位中文技术博主整理：OpenAI 说全球用户每周在 ChatGPT、Codex 和 API 上生成大约四十亿张图，平均每天超过五亿张。这个数字是官方自称，没有第三方核对。

新能力里，最受关注的是导出 SVG 矢量图，以及用提示或图片生成可调速、可逐帧改的 GIF。SVG 写在开发者功能里，公告没有明确说 ChatGPT 能否直接导出。API 还有图片标注和「复杂度」参数。定价方面，Flare 与 Sunburst 同价，和二点五相同。

中文圈几位博主演示了 GIF 表情包。有人说 Codex 里暂时调不了二点六。

我们的看法是：速度和周出图量都是 OpenAI 自己的说法。对普通人更有感的，是 GIF 和参考图复用；对开发者，SVG 和标注能不能稳进生产，还要看实际文档和工具链。

## 重点二：九百四十八个 Linux 本地提权，和 GPT 六 Cyber

为什么重要？因为这是「智能体自动打洞」第一次给出这么具体、又面向防御叙事的数字。

OpenAI 安全研究团队称，建起自主的漏洞发现、利用与补丁流水线：扫描相关代码、在隔离环境复现、测试可否利用、生成候选补丁，再由人类审阅后向维护者报告。这一点很关键：最后一环仍是人。

单次运行用「即将发布的 cyber 模型」，复现一千七百二十四个漏洞，产出二百九十一个信息泄漏概念验证，以及九百四十八个在标准 Linux 桌面防护下可用的本地提权利用。全文 API 成本大约一百二十一万美金，约合每个独立本地提权一千二百七十九美元。按历史赏金粗算，假想价值大约一千八百九十万到六千六百三十万美元。官方还称，代理发现并使用了至少十种据他们与咨询专家所知属新的 Linux 利用手法，并在与 Linux 维护者和 Patch the Planet 合作报告与补丁。

次日正式发布 GPT 六 Cyber，称驱动了上述研究；Mozilla、Palo Alto Networks、Cisco 等安全团队已在使用。现对部分 Daybreak Red 客户开放并逐步扩大。Daybreak Blue 帮防御方核对漏洞与修复；Daybreak Red 面向授权渗透。山姆·奥特曼转发称，这对防御者是有意义的一步。

我们的看法是：这些是 OpenAI 的研究叙事，数字未经第三方审计。人类审阅和向维护者报告，是他们自己强调的护栏；对笔记本自动装包、供应链和「防御窗口会不会被压缩」，后面评论再展开。

## 重点三：Cat Wu 加入 OpenAI

为什么重要？因为 agent 产品负责人的跨实验室流动，会直接影响「用户可控的智能体」由谁定义。

前情是前天：Cat Wu 离开 Anthropic 与 Claude Code。昨天她本人宣布加入 OpenAI，领导核心产品的产品管理。她说尊重 OpenAI 证明规模化、把 AI 带给超过十亿人、并把好产品当作使命核心；将与产品团队一起做「站在你和团队这边、仍由你掌控」的智能体。

编程博主 Theo 总结轨迹：「Claude Code，到 Cursor，再回 Claude Code，再到 OpenAI」，称这是一代人级别的履历。几位中文博主跟进；有人说以往多是 Anthropic 从 OpenAI 挖人，现在反过来了。

同一天还有 Anthropic 首位增长员工 Austin Lau 也去了 OpenAI。他此前在 Dropbox、Notion 做增长，自称从没写过代码，却用 Claude Code 做出批量出广告图和搜索广告文案工具。

我们的看法是：去向和公开表态是事实；动机原帖没有细说，我们也不猜。产品负责人换实验室，比单纯模型跑分，更能改变默认产品形态。

## 重点四：METR，Anthropic 进步约翻倍

为什么重要？因为它直接碰到「AI 加速 AI」会不会失控，以及公众能不能核查证据。

METR 前天发布报告：八月中至十月底、大约两点五人年等价投入、没收 Anthropic 的钱。截至二零二六年十月，Anthropic 在「目标明确任务」上提升模型能力的速度，大约是二零二四年三月到二零二五年十月的两倍。METR 说很不确定，一点三倍或三倍都不意外。

三条主观结论：速度约两倍；加速大部分可能来自大量用 AI 做研发，METR 猜约占八成，内部无共识；未来十二个月可能更快加速。公开最具体证据是 Anthropic 版 Epoch 能力指数：二零二五年十月以来增速约为此前一点九倍，高于 Haiku 五点五系统卡的一点七倍，因计入三个未发布内部模型。

约一百页完整报告中，Anthropic 删掉了 METR 认为最有说服力的大部分证据，公开推迟约五天。原计划核查算力在能力与安全间的分配，被中途取消。联合创始人 Sam McCandlish 称许多结论与他一致，承认涂黑让外界更难核查，理由是公开加速机制等于给别人路线图；称未来几周 Anthropic 会发自己的进度与负责任扩展政策对照报告。

我们的看法是：独立评估本身有价值；但公众只能更多依赖 METR 的判断，透明度打了折扣。是不是失控，报告自己也说不确定。

## 重点五：Thariq 访谈，别把实验室偶像化

为什么重要？因为 Claude Code 最常露面的工程师之一，公开谈了实验室光环和勇气。

前情是十月底他离开 Anthropic。后续：一位中文技术博主编译他在 SOTA Wives 播客的长访谈。他说某周五下午三点停用公司邮箱，六点消息已在 X 传开：有人盯邮箱失效，有人在共用 Slack 发现。本想安静休息，结果别家公司的首席执行官都来私信，只好自己发帖。离职原因与去向仍未正面答，只说歇着、打《魔兽世界》、回家看父母。

核心观点：实验室被捧得太高，里面也只是普通人；身份不该绑在公司上；湾区聪明人太多，缺的是「不去实验室自己试」的勇气。他形容 Anthropic 日常更像赫奇帕奇式埋头干，OpenAI 像格兰芬多。创业公司 Multiverse 在 YC 疫情演示日融到公开报道大约一千七百五十万美元，账上大约一千五百万却只有七八人，他称融资过度，最后关掉并把钱还给投资人。从 GPT 二、GPT 三起玩 AI，进 Anthropic 看重编程能力。还谈「种和收」：有意思的内容来自先做枯燥的事；一旦不再做那些枯燥的活，就写不出东西了。

我们的看法是：人事动机仍未公开，不猜。他的「勇气比天才稀缺」，对还在观望要不要自己做产品的人，比任何跑分都实用。

## 重点六：一天三万次合并，人看的是证据

为什么重要？因为它把「软件工厂」从口号落成可操作的流程：写代码不再是瓶颈，验证才是。

一位中文技术博主整理 AI Engineer 台上对谈：Anthropic 从今年五月每天大约两千五百次合并，到九月超过大约三万次；claude.com 网页重做，短时间合并大约三千个拉取请求。

做法是：Claude 先像真实用户做端到端、浏览器和规范检查，钩子自动修，品味写入团队配置文件，人再看录屏与截图等证据。瓶颈从写代码转到验证，也就是端到端、属性测试、视觉对比。他用「亮灯、熄灯软件工厂」打比方：多数团队在中间，到二零二七年底他判断仍以亮灯为主，带一些熄灯角落。AI 开的拉取请求他认为应标注，责任仍在人。

我们的看法是：三万这个数字是台上叙述，没有附原始仪表盘。但「人看证据而不是看每一行生成代码」，和昨天我们聊的审代码瓶颈，是同一件事的另一面。

## 重点七：Jupyter 被 AI 安全报告淹没

为什么重要？因为「AI 漏洞猎人」的外部成本，已经落到维护者日历上。

Project Jupyter 在 Mastodon 与 Bluesky 同步：安全在二零二六年用户调查中排名靠后，但跨二十二个 GitHub 组织、四百多个仓库，今年已收到一百八十一份 GHSA，也就是 GitHub 安全公告；九月单月创纪录四十份，主因是 AI 生成报告激增。委员会在做供应链安全、优先级工具与新安全贡献者入职。博客讨论 Jupyter 安全为何难：仓库多、攻击面散。

同一天，欧洲开放科学云节点新版上线，更大虚拟机、Conda 切换器支持可复现 JupyterLab、令牌获取器支持安全实时协作。有编辑器原生支持笔记本文件格式。这些是建设性的一面；安全报告洪峰，是消耗性的一面。

我们的看法是：报告多不等于漏洞多，但分诊本身就是成本。这和后面 pyOpenSci 说的「人消失」，是同一条压力链的两端。

重点就到这里。

## 一起讨论

下面进入评论环节。每一条，我们会讲清楚原帖说了什么，也会明确说出我们自己的判断。

## 评论一：Cat Wu，谁在定义可控的 agent

先讲事实。Cat Wu 前天离开 Anthropic，昨天宣布加入 OpenAI 领导核心产品管理。她的公开表述强调：智能体要站在你和团队这边，仍由你掌控。Theo 把她的轨迹总结成一代人级别的履历。中文圈注意到，挖人方向似乎反转了。

我们的判断是：这不只是八卦。Claude Code 把「人在回路的编程智能体」做成了默认体验；她去负责 OpenAI 核心产品，意味着两家对「用户可控」的产品定义，可能会互相参照，也可能互相分化。跨实验室流动，会加快这种对照。

原帖没有说她为什么离开，我们也不猜动机。

给你一个具体建议：如果你在选编程智能体，这周专门看一眼「哪些操作必须你确认、哪些会自动跑」。产品负责人换防之后，默认权限往往是最先动的地方。

## 评论二：METR 涂黑，透明度打了折

这一条有硬判断，也有争议。

原帖核心：METR 说进步大约两倍，大半可能来自 AI 做研发；约一百页报告里最有说服力的证据被删，公众只能更多依赖 METR。Theo 对「最有说服力证据被删」发了一声无奈。Anthropic 联合创始人承认涂黑，理由是公开等于给别人路线图。

我们的判断是：商业机密和公众知情之间的张力是真的。但「AI 加速 AI」若真是负责任扩展政策里的关键风险指标，删掉核查所需的证据，会削弱外部约束。METR 没收钱、也写明不确定，这是加分；取消算力分配核查，是减分。

最有力的反对意见：公开加速机制，可能让别人更快追上，风险更大。这话成立的前提是，外部审计没有替代方案。分层披露、延迟披露、只给可信评估方看，也许比大面积涂黑更稳。

给你一个具体建议：读实验室安全承诺时，先问一句「独立评估能不能看到原始证据」。看不到，就把结论当待核实，而不是当定论。

## 评论三：九百四十八个提权，防御窗口在缩吗

换案例型。

OpenAI 给出的故事是：智能体流水线大规模找洞、写利用、提补丁，人类审阅后交给维护者，并发布面向防御的 GPT 六 Cyber。数字很炫：九百四十八个可用本地提权，大约一百二十一万美金 API 成本。

我们的判断是：若流程属实，对防御方是能力增强；但同一套能力，也压缩了「漏洞被发现到被利用」的时间窗。关键不在吓不吓人，而在三件事是否真落地：隔离环境、人类审阅、与维护者协同披露。官方把这三件事写进了叙事，第三方还没复现。

这和笔记本、智能体自动装包直接相关。智能体若能自己 pip install、自己拉依赖，攻击面就从「人点链接」变成「agent 代你点」。

最有力的反对意见：没有这类工具，攻击者照样会用模型找洞，防御方反而更慢。所以问题不是做不做，而是访问控制给谁、披露节奏怎么定。

给你一个具体建议：若你的智能体会自动装包，给它一份允许的包来源白名单，并关掉随意执行远程脚本。这比争论模型该不该懂安全，更能立刻降低风险。

## 评论四：维护者更怕「人消失」

这一条来自 pyOpenSci 的 EuroPython 焦点小组。

十五位科学 Python 与 Linux 核心维护者谈了两小时以上。相对「审查更耗时」，更反复出现的是人际连接丧失：分不清对面是不是人；贡献者在 AI 加持下误以为自给自足；为过招聘过滤而刷 GitHub 的「业力种植」。有人重做机器人小修复，以免把功劳记给智能体；all-contributors 机器人维护者刚封了一个数小时内刷数十个拉取请求的明显智能体号。

一致反对全面禁止 AI，倾向灵活指南：先开 Issue 建立对话、披露 AI、质量标准不变、用参会等方式核实关心项目的真人。

我们的判断是：这比「AI 让开源崩溃」的标题更准确。科学开源靠的是信任和反复出现的真人。AI 可以写补丁，但不能替代「我认识这个人、他下周还会来」的那种连接。全面禁止只会把使用逼入地下。

给你一个具体建议：若你用 AI 给科学 Python 或 Jupyter 相关项目提拉取请求，先开 Issue 说明意图，并在描述里写清哪些部分由 AI 生成、你核对了什么。这是维护者反复提到的最低礼貌。

## 评论五：Jupyter 的 AI 安全报告洪峰

最后一条，和上一条是同一条压力链。

事实：二零二六年跨二十二个组织、四百多个仓库，一百八十一份 GHSA；九月单月四十份；主因 AI 生成提交。用户调查里安全还排在最后。委员会在做供应链、优先级工具和新贡献者入职。博客写得很直白：Jupyter 安全难，是因为仓库多、攻击面散，不是因为大家不在乎。

我们的判断是：AI 降低了提交安全报告的成本，却没有自动提高报告质量，于是成本转嫁到维护者。这和 OpenAI 展示的自动打洞能力，方向相反、结构对称：一边是有资源的实验室规模化找洞，一边是志愿者项目被低质量报告淹没。中间缺的是分诊标准和信任信号。用户调查把安全排在最后，并不等于风险低，只说明痛感还没传到大多数终端用户；洪峰先砸在维护者头上。

最有力的反对意见：宁可报告太多，也不要漏掉真漏洞。对。所以解法不是禁 AI 报告，而是给报告打分、要求可复现步骤、对重复与无效提交限流。

给你一个具体建议：若你维护 Jupyter 或同类项目，这周看一眼安全分诊流程有没有「可复现清单」；若你提交报告，先在干净环境复现一遍再交，别把模型的第一稿直接贴上去。
