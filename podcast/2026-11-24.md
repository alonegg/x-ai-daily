## 重点二：Claude Ship

主持：第二个重点，Claude Ship。先说它是干嘛的。

解读：你在 Claude Code 里打一个斜杠 ship，它帮你推代码、开合并请求、自己审一遍，再处理反馈和失败的测试。

主持：它其实是三个部分拼起来的吧？

解读：对。第一个是代码审查，已经正式上线了，可以选快速、标准、深度三档。

主持：第二个叫 PR Steward，像个管家。

解读：测试挂了、代码冲突了、有人提意见了，它去修。每次推送都留言说改了什么、怎么撤回。

主持：但它不批准，也不合并，这个设计我挺认可。

解读：批准的是第三个，Claude Approvals。团队把规则写成一个文件放进仓库，常规改动它可以直接放行。

主持：有点像更聪明的代码负责人名单。

解读：没错。特殊情况，它会要求人来签字。

主持：效果有数据吗？

解读：官方说，Claude Code 团队从六月到九月，合并的请求多了一倍多。

主持：质量没跟着掉？

解读：被回滚的比例反而降了四成以上。

主持：不过那是他们自己团队，而且审查只是流程里的一层。

解读：对，这个前提要记住。收费是按 token 算，管理员可以设每月上限。

主持：符合条件的企业客户，还能领至少一万美元额度。

解读：Boris Cherny 说，一年前模型已经写他全部的代码了，但发合并请求的速度没跟上。

主持：我的疑问在开头说过了。写的、审的、批的，都是同一家模型。

解读：我倒没那么担心。它审查时会对每个发现做对抗式复核，而且人可以写规则，决定哪些必须人看。

主持：可模型的盲点是系统性的。它写的时候想不到，审的时候大概率也想不到。

解读：这点我同意。所以官方自己建议，先用只观察模式跑，不让它真的卡合并。

主持：也就是说，先看它会批什么，跟人的判断对一对。

解读：对，Boris 也说先挑一个仓库试。我觉得那份规则文件才是关键，写得太宽，就等于没审。

主持：我还会加一条：涉及权限、支付、数据删除的改动，永远要人看。

解读：合理。这类改动错一次，代价远大于省下的那点时间。

## 重点三：模型自己改自己的权重

主持：第三个重点挺有意思。一个开源模型，自己动手改了自己的权重。

解读：是 UIUC、CMU、斯坦福等学校十一位研究者的论文，十一月十八号发在 arXiv 上。

主持：用的是 Qwen 三点五，二百七十亿参数那个。

解读：他们禁掉了所有训练工具，只给一块显卡，跑几个小时，让模型自己写 Python 改权重。

主持：它先得知道自己哪儿不行吧？

解读：对，它先复盘做题记录。发现问题不是不会算，写完的题九成六都对，而是爱钻牛角尖，话没说完就超长了。

主持：宝玉举的那个例子特别形象。

解读：一道数数题，它把同一句英文复读了五百四十九遍，直到卡死。

主持：那它怎么改的？

解读：就改了一处。四十八层里，控制旧信息消退快慢的那个参数，统一调高零点五。

主持：说白了，就是让它别老在原地打转。

解读：对。在四百九十道没见过的题上，没答完的比例从百分之三十三点六降到二十六点一。

主持：准确率涨了六点六个百分点。

解读：而且改动直接写进权重，以后用不用加提示，也不多花算力。

主持：还有个修复的实验，我觉得更惊人。

解读：研究者故意把第三十层一个矩阵弄坏，模型数学直接零分。只告诉它有数值坏了，它自己一层层查出来，把异常值压平了。

主持：修回来多少？

解读：数学恢复到三十三分，原版是五十八点五。看图测试从七点三回到七十点二，原版八十四点三。

主持：有人在转述时，把八十四点三说成修好后的分数，这个要注意。

解读：对，那是原版的成绩。还有个关键限制，宝玉专门提了。

主持：是说八轮都是从原版重新开始吧？

解读：对，不是改完再接着改。所谓八轮只升不降，其实是它撤回了五次失败，只提交了三次成功的改动。

主持：小模型呢？

解读：完全不行。二十亿参数那个，直接说自己改不了权重。

主持：九十亿那个呢？

解读：更惨，它往权重里乱加噪声，把自己从四十七点五分改成了零分。

主持：我觉得这其实是个好消息，说明这事有门槛，不是谁都能失控。

解读：我看法稍微不同。门槛在模型能力，而模型能力每半年就涨一截，今天的二百七十亿，明年可能就很普通了。

主持：那你觉得该担心？

解读：不是担心，是该提前定规矩。比如自我修改必须留记录，能回滚，还得在没见过的题上验证。

主持：这篇论文自己倒是做到了这几点。

解读：对，它是个干净的起点。不过只在一个模型家族、只在数学题上测过，也还没经过同行评审。

## 重点四：Alexandr Wang 谈超级智能

主持：接着说递归自我改进。Meta 首席 AI 官 Alexandr Wang 发了篇长文。

解读：题目叫超级智能正在到来。他把黎曼猜想被证明，当成一个转折点。

主持：他说话挺狠，说跟它比，造原子弹只算家庭作业。

解读：对，他说很多物理学家会同意这一点。他的主线是，模型已经够聪明了，缺的是各行各业的专门知识和做实验的条件。

主持：然后他说 AI 研究本身也会被自动化。

解读：对，生物、武器、经济这些研究，可能快到人类看不懂、管不住。

主持：但他的结论不是加速，是说社会不该把控制权交给 AI。

解读：他说很难控制一个比人强一千倍的系统，整个行业得换条路走。问题是，文章没说换哪条路。

主持：Juan Benet 就直接追问了：你具体设想的是什么？

解读：后来有人骂这是疯了，他回应说，这些话别的实验室负责人也说过，他想强调的是这条路不是必然的。

主持：他还举了 Meta 自己的例子？

解读：对，说为了安全把 Muse 的发布推迟了几个月，扎克伯格也呼吁各家把大部分算力用来服务用户，而不是自我改进。

主持：我有点不买账。一边全速往前跑，一边说别走默认路线，说服力有限。

解读：我倒觉得，一个大实验室负责人公开说不可接受，本身就有分量。别家员工也会拿这句话去问自己老板。

主持：可是没有具体做法，最后很容易变成一句表态。

解读：这个我认。另外数学圈也有不同声音，LeCun 转发了一个观点。

主持：说数学其实分两种活？

解读：对，一种是用现有方法证明猜想，一种是发明全新的数学领域，比如微积分、拓扑。前者 AI 能做不奇怪，后者才算真本事。

主持：Ethan Mollick 反过来说，别忘了 LLM 直到最近都不擅长数学。

解读：他还引了一个社科研究的盲评。专家给模型写的研究设计打分，比哈佛一位知名政治经济学家的论文还高。

主持：但整体贡献那一项，模型没占优。

解读：而且专家之间对贡献怎么打分，一致性只比随机好一点。这说明有些价值，本来就不好量。

主持：那我的结论是：技术执行，AI 进步很实在；提出好问题，人还占着位置。

解读：我会说暂时占着。至于能占多久，别太早下结论。

## 评论一：OpenAlex 开放作者贡献角色

主持：评论环节，先聊个开放科学的。OpenAlex 开始记录每位作者在论文里干了什么。

解读：用的是一个叫 CRediT 的标准，把贡献分成十四类，比如方法、数据整理、写初稿。

主持：他们的比喻挺好：电影片尾字幕会写每个人干了什么，论文为什么不能？

解读：现在大约三百万篇论文有了这类数据，完全开放，谁都能用。

主持：数据从哪儿来？

解读：主要是论文正文里的作者贡献声明。只有用了标准术语、每个角色都能对上署名作者的，才记下来，从不按署名顺序去猜。

主持：准不准？

解读：他们请了两家公司的模型各自读三百篇来对照，记下的角色九成九以上一致。

主持：我觉得这对评职称挺有用。做数据、做软件的人，终于有地方留名了。

解读：可我有点担心另一面。一旦这些角色进了考核，大家就会抢着往自己身上多挂几个。

主持：角色通胀？

解读：对。而且覆盖不均匀，二零二二年以后的文章，也才百分之七左右有角色记录。

主持：OpenAlex 自己也提醒，没记录不代表这个人没干活。

解读：这句话很重要。考核的人要是忽略了，没被收录的那批人就吃亏了。

主持：所以我会这么用：先拿来研究团队怎么分工，暂时别直接拿来打分。

解读：同意。研究分工的话，以前只能用几万篇样本，现在一下子到了几百万。

## 评论二：agent 评测，到底能信多少

主持：第二个评论，说说 Hugging Face 那篇评测文章。

解读：开头那个数：同一个模型，只换外面那套运行框架，准确率最多能差将近三十个百分点。

主持：三十个点？那排行榜上差两三分，岂不是没意义？

解读：很可能是。还有一个，百分之九十八点二的分数，都只有一方自己报的，没人独立复现。

主持：他们自己做演示时，也翻了车？

解读：对，第一版评测有漏洞。一个跳过计算、直接读数据的偷懒脚本，八道题全拿满分。

主持：这跟 Claude Ship 那个担心是一回事：检查的规则写得不好，什么都能过。

解读：没错。Anthropic 那门评测入门课也讲到这点，门槛要按错一次的代价来定。

主持：他们那个例子挺具体，错一次要人工查五分钟，所以门槛定在九成。

解读：而且发现模型老是编造风险，是因为提示词没说什么时候该返回空。改完，最便宜的模型也全对了。

主持：所以我的看法是，先修评测和提示，再考虑换贵的模型。

解读：我补一句，自己的评测集也会坏。文章说一个知名基准查了一百三十八题，近六成有实质问题。

主持：那普通团队怎么办？

解读：从二三十条真实案例开始，人先写好标准答案，定期抽查。别指望一次做完。
