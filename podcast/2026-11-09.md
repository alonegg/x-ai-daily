## 重点一：Anthropic 的科研会话报告

主持：重点一，Anthropic 的科研会话报告。它用大规模真实使用数据，回答人工智能到底让科研快多少，同时还把「科学家自己最看重什么」和「实际把时间花在哪」对上了。

解读：报告十一月四号发布。样本是八月二号到九月三十号，大约二十点七万次科研相关 Claude 会话：聊天和 Cowork 约十二点九万，Claude Code 约七点八万，来自个人订阅用户。

主持：他们实际把人工智能用在哪？

解读：分析数据：占科学家自述科研时间大约百分之二十八，却占 Claude 聊天约三分之一，在 Claude Code 里接近一半。

解读：写作和沟通：自述时间大约百分之十六，聊天里大约三分之二。

解读：收集数据自述大约百分之二十九，在 Claude 上只有大约百分之十二。

主持：调查里「提想法」不是最重要吗？实际用得怎样？

解读：对五百二十八位科学家的调查里，「提想法」重要性最高。但在自述科研时间里大约百分之七，Claude 会话大约百分之四，Claude Code 大约百分之二。报告的解释方向是：收集数据多半要动手；提想法科学家更愿意自己来，模型在选题上也可能更弱。

主持：还有没有更硬的规律，不只是问卷？

解读：有。团队给七千多项任务打「人工智能能力分」。能力分前百分之二十的任务，比如画图、做统计检验，使用倍数大约是聊天两倍、Claude Code 四倍；并且和「适不适合强化学习」相关系数大约零点七八。人是在反馈快、对错好判的地方用人工智能。

主持：那些十五倍、两倍的推算，听的时候最容易被标题带走。哪些前提必须一起说？

解读：报告写明不是预测。现有能力普及后，人工智能能接手大约百分之二十七到五十二的科研时间，产出大约一点四倍到两倍。

解读：若包揽全部不用动手的步骤，统计、计算机一类可到大约十五到十六倍；生物、化学、材料大约三到四倍——大约四成时间卡在动手步骤。

解读：十六倍上限还绑着成本假设：研究员每小时九十五美元、人工智能每小时三十美元。样本偏美国加拿大生命健康、且申请过 Anthropic 资助，用人工智能比一般人多。

主持：如果实验室自动化做不起来，这些倍数会怎样？

解读：会停在纸面。瓶颈常常不在「会不会写」，而在「能不能在真实世界里自动做完实验」。

解读：区间当区间，别把买方聊天写成「已经值」。更有用的问题是：产品层的上下文和信任，能不能在同质化压力下站住。

## 重点四：智能体工程，验证和审查成了主线

主持：重点四，智能体工程。Warp 的 Ben Holmes 讲得很刺：智能体说「完成了」，不代表过程没问题。

解读：案例是 Skills 里的端口说明过时了。智能体绕开错误指令、反复试错后仍交付成功，团队只觉得「慢一点」，没发现该修的是说明本身。建议流程：先定评分标准，再用评审智能体查记录扣分，第三个智能体汇总反复问题，把修复变成技能或配置的合并请求交人审。

主持：宝玉和 Addy 分别补了哪一块？

解读：宝玉要的是给验收人看的证据：截图或录屏。智能体自己可能截过图，但对你仍是黑盒。Addy Osmani 把自验证放首位——测试、构建、类型检查，界面改动可用截图；必要时让没参与原对话的新智能体独立审查。无人值守任务开始前写清完成条件、验证方式、权限、上限、交付物和审批人。成效应看交付周期、返工和回退，不是看写了多少行。

主持：那为什么很多人用上智能体之后反而更忙？

解读：忙往往来自规则堆太多、旧约束不清、又没有强制安全闸。模型升级后要清理规则；必须遵守的，靠机制而不是靠多写几句提示。

## 重点五：李博杰拆解全双工语音模型的成本

主持：重点五，全双工语音。李博杰认同它是技术上限方向，但不一定适合大规模商用。

解读：贵在两头：预训练数据要重做；推理更贵。他引 Higgs 博客的设计目标：一小时成本至多是人时薪的十分之一——按美国时薪大约五十美元，也就是大约五美元一小时。

主持：架构上，贵具体贵在哪一步？

解读：输入大约每一百六十毫秒送进几个词元。现有推理引擎若全局键值缓存反复换入换出，就不划算；更合理的是键值常驻显卡，像节拍器一样按固定间隔服务一批用户。

解读：他的估算：大约二千三百五十亿参数、激活约二百二十亿这种规模。

解读：间隔大约两百毫秒时，一台八卡机器大概只能服务大约十六个并发。

解读：单用户大约两点五美元一小时，接近某家实时语音定价大约三美元一小时。

解读：大约四百五十亿参数的混合专家可降到一美元一小时内。这些是他的估算。

主持：那传统「听写、模型、播报」三段式，是不是就被判过时了？

解读：他认为传统三段式本质是在时间和语义上做稀疏化；延迟高常常是基础设施没优化好。他们二零二四年就做到大约六百毫秒；加一次快速工具调用，语音到语音今天可以在一点五秒以下。全双工是上限，不等于今天唯一可卖的形态。

## 评论一：Asahi 禁用 AI，开源社区被切开了吗

主持：进入评论。第一条，Asahi。先把两件不同的事分开：一是官方生成式人工智能政策，二是许可证迁到 GPL 第二版或更新版本，三是 DHH 称因智能体加速被拒上游。

解读：我核对过 Asahi 官网的生成式人工智能政策页。原文写的是：广泛禁止把生成式人工智能工具用于对 Asahi Linux 的实质性贡献；执行按情节，从关闭议题到警告再到封禁不等。它禁的是贡献路径上的生成式工具，不是宣布软件本身不能给普通人用。

解读：许可证变化写在十一月进度报告里：因有人从个人分支拿走未发布代码、或不署名、或用大模型改写掩盖来源，项目开始把仓库迁到 GPL 第二版或更新版本。DHH 澄清过：内核本来就是 GPL 第二版；Omarchy 自身是 MIT，他们对内核的改动都公开。他引用的那句「全面禁止生成式人工智能」来自政策页精神，但政策原文限定在实质性贡献。

主持：Steinberger 说拒绝人工智能「很傻」；mitsuhiko 先难过，后又说完全理解。争论真正打在哪？

解读：打在两层。维护者有没有权设定贡献门槛——有。用贡献禁令与强 copyleft 保护逆向工程与归属，会不会同时抬高协作成本——这是 Steinberger 一侧的批评。mitsuhiko 后一条更像降温：先承认成就与权利，再谈分裂感。

主持：听完之后，维护仓库的人最不该做的是什么？

解读：最不该把情绪站队当成政策。更有用的是写成可执行规则：是否允许人工智能辅助、要怎样披露、怎样验收。贡献方被拒时，也先分清拒的是许可、质量，还是生成式工具本身。

## 评论二：科研自动化，瓶颈在实验室

主持：第二条，接着科研报告。有人听完会说：十五倍要来了。报告自己把上限和动手比例写在一起了吗？

解读：写在一起了。统计、计算一类少动手，上限高；生物化学材料大约四成时间在实验台，上限就矮。开放科学若只自动化写作与画图，实验室协议和设备接口不动，倍数会停在纸面。

主持：和昨天 Mollick 转述的「百分之二十七到五十二」是同一份吗？

解读：是同一报告族谱上的数字。今天多出来的，是「用在哪」和「能力分高的任务才被用」这两层结构，不只是一个加速区间。

## 评论三：Anthropic 的估值，别把区间当结论

主持：第三条，估值。买方聊天从大约两万亿美元口头高位，落到大约一万二千亿到一万三千亿美元。

解读：这证明预期在改，不证明「内在价值」被精确测出。私募参照、大盘下跌、监管想象，都会拧动区间。姚顺雨谈产品层护城河，张亚勤用玩笑戳同质化——两者都比「今天值多少」更接近长期问题。

主持：转述这些数字时，最少要带上哪几句限定？

解读：「还在商量、不予置评、路演未定价」。没有这三句，区间很容易被听成成交价。

## 评论四：智能体说完成了，你要看到什么

主持：第四条，验收。你要是只看最后一行「完成了」，会漏掉什么？

解读：会漏掉过时说明、重复试错、低效工具调用，以及「成功但走了不该走的路」。证据可以是截图、录屏、测试日志、独立审查智能体的报告。没有证据的完成，只是叙事。

主持：这和笔记本、自动执行有什么共同点？

解读：共同点是运行记录要可审查。谁都能生成一段「我做完了」；真正可争辩的是你能不能复现路径，定位该修的是模型还是技能文档。

## 评论五：Infinite Slop TV 为什么收官

主持：第五条，levelsio 给 Infinite Slop TV 写讣告。项目大约八月跑到十月：聊天写提示，驱动永不重复的实时生成视频流。

解读：硬数据他给得很齐：大约一千七百八十万次片段观看，大约十二万六千条消息被审核拦住，大约百分之四十四。他称此前没有「生成快过播放」的模型，是 fal 把 MiniMax H 三优化到够快，并赞助算力，否则显卡成本至少大约二十万美元每月。

主持：他的「会上瘾但一阵子就无聊」，你怎么接到审核成本上？

解读：和审核拦下四成多消息是同一枚硬币：实时生成降低内容门槛，也把垃圾与伤害的成本前置。他看好未来的个性化实时内容，但明说还没到。葬礼帖的价值，是把成本表和体感一起公开，而不是只晒播放量。
